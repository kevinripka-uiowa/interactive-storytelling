Finding and Using Open Source Media

Open media can help you build richer stories without creating every image, video clip, sound, icon, font, or dataset yourself. The key is to use material that is actually reusable and to credit it clearly.

Core idea: “online” does not mean “free to use.” Look for a clear license or public-domain statement, save the source link, and attribute the creator in the format the license requires.

Where to find usable media

Start with sites that expose license information clearly. Still check the item page before downloading because individual items can have different licenses, restrictions, or attribution requirements.

Check before using

Make the license check part of production. It is easier to document rights when you download the asset than when you are finishing the project.

Five-minute rights check

Before using an external asset, confirm the source, rights status, and whether your planned use fits the license.

Verify

1. Find the original page

Use the item page, not only a search result, thumbnail, repost, or preview.

2. Read the license

Look for Creative Commons, public domain, CC0, government/public record, or a site-specific license.

3. Check your use

Editing, commercial use, embedding, music, people, logos, and AI-generated derivatives can change the risk.

4. Save the evidence

Save the source URL, creator name, title, license, and date accessed in your project notes.

5. Write the credit

Add a visible credit near the media or in a credits/source section.

6. Replace unclear assets

If the license is missing or confusing, choose a clearer source.

Creative Commons licenses

Creative Commons licenses let creators give the public permission to reuse work under standard conditions. All current CC licenses require attribution except CC0, which is a public-domain dedication.

Creative Commons variants

The abbreviations tell you what you may do and what you must preserve.

CC

What it allows

Reuse, remix, adapt, and redistribute, including commercially, as long as you give credit.

Attribution note

  • Credit the creator.
  • Link the source if possible.
  • Name and link the license.
  • Note changes if you modified it.

What it allows

Reuse and adapt the work, including commercially, if you credit the creator and license your adaptation under the same or a compatible license.

Attribution note

  • Use a standard attribution.
  • Keep the ShareAlike requirement if you publish an adaptation.

What it allows

Reuse and adapt for noncommercial purposes with attribution.

Attribution note

  • Good for many class projects.
  • Riskier for client work, branded work, ads, sponsored projects, portfolios used for business promotion, or anything that might be commercial.

What it allows

Noncommercial reuse and adaptation with credit, as long as the adapted work uses the same or compatible license.

Attribution note

  • Credit the creator.
  • Keep the NC limit.
  • Apply the ShareAlike condition to adaptations.

What it allows

Redistribution with credit, including commercially, but not adapted or remixed versions.

Attribution note

  • Use as-is.
  • Do not crop, remix, edit, recolor, translate, overdub, sample, or modify in a way that creates an adaptation.

What it allows

Sharing the original work with attribution for noncommercial purposes only. No adaptations.

Attribution note

  • Most restrictive common CC license.
  • Usually poor fit for edited video, remixed audio, design treatments, or interactive graphics.

What it allows

The creator has waived copyright and related rights to the extent possible. Attribution is not legally required by CC0, but credit is still good practice.

Attribution note

  • Use a short credit when practical.
  • Still check for privacy, trademark, or ethical issues.
Reference: See the Creative Commons licenses and CC public-domain tools.

Public domain

Public domain means the work is not restricted by copyright, usually because the copyright expired, it was created by a government source that does not claim copyright, or the rights holder waived rights through a tool like CC0.

Other open licenses

Not all reusable media uses Creative Commons. Some sites and asset types use their own licenses. Treat these as “read the specific license” situations.

Licenses and attribution

Attribution should be clear, close enough to the media to be useful, and consistent across the project. A credits section is fine for large projects, but the source must still be easy to find.

Terse attribution patterns

Use the shortest credit that still includes the required information: title, creator, source, license, and changes when needed.

Credit

Standard Creative Commons credit

“Title” — Creator, Source, License.

Example: “City Hall at Night” — Maya Lee, Wikimedia Commons, CC BY 4.0.

Creative Commons credit with edits

“Title” — Creator, Source, License. Cropped / edited / adapted.

Example: “Harbor Aerial” — Jon Reyes, Flickr, CC BY-SA 2.0. Cropped and color corrected.

Untitled Creative Commons media

Media by Creator, Source, License.

Example: Photo by Aisha Morgan, Openverse / original source, CC BY-NC 4.0.

Public-domain archival media

Title, Creator/Agency, Year. Public domain. Source.

Example: “Main Street Flood,” U.S. Geological Survey, 1936. Public domain. Library of Congress.

CC0 or attribution-not-required stock

Photo: Creator / Source.

Example: Photo: Lena Novak / Unsplash.

Audio or music

“Track/Sound Title” — Creator, Source, License.

Example: “Morning Ambience” — Diego Santos, Freesound, CC BY 4.0.

Shortcut: Creative Commons recommends attribution that includes Title, Author, Source, and License. When in doubt, add a change note if you modified the work.

Common cautions

Licenses answer copyright questions. They do not automatically solve every legal, ethical, or editorial problem.

Do not skip these checks

These issues are common in student multimedia projects.

Caution
No license listed: do not use it unless you have permission or a strong public-domain basis.
NonCommercial: okay for many class exercises, but risky for client work, branded work, sponsored work, portfolio promotion, or anything that could be commercial.
NoDerivatives: avoid if you need to crop, edit, remix, translate, animate, sample, recolor, or combine the work into a new design.
People and private property: a copyright license does not always mean you have model releases, property releases, or permission for sensitive portrayals.
Logos and trademarks: open licensing does not necessarily allow implying endorsement or misusing brand marks.
Music: be especially careful. Platform copyright systems may flag music even when you have a license, so keep your source and license records.
AI-generated media: check the platform terms and avoid presenting synthetic media as documentary evidence.
