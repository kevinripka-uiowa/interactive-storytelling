Tutorial M4 - A

Build a Choropleth Map in Datawrapper

In this tutorial, you will create an interactive world map showing population density by country. You will match spreadsheet data to geographic regions, refine a color scale affected by extreme values, customize the tooltips, add an annotation, and embed the finished map in Tilda.

Choropleth maps are easy to make and easy to misuse. The mapped value, geographic units, color scale, and visual framing all affect what the reader believes the map shows.

What you will build

A zoomable choropleth map of world population density with customized tooltips and a text annotation.

What you will submit

The public URL to the published Tilda page containing your embedded Datawrapper map.

Video walkthrough

Purpose and map choice

Begin by identifying what each Datawrapper map type does and why a choropleth map fits this data.

Compare the three map types

Datawrapper separates maps according to the geographic marks and interaction they use.

Tool choice
  • Locator maps identify and label places. In Datawrapper, they are static rather than pan-and-zoom slippy maps.
  • Symbol maps place symbols at locations and can vary their size, color, or both according to data.
  • Choropleth maps fill geographic areas with color according to a value.
This tutorial uses a choropleth: Each country is a geographic area, and the color will represent population density within that area.

Section 1: Select the map

Choose the geographic boundaries that Datawrapper will join to your spreadsheet.

Create the map and choose World

Datawrapper includes built-in vector maps made from selectable geographic regions.

Setup
  1. Log in to Datawrapper.
  2. Choose Create new, then select Map.
  3. Select Choropleth map.
  4. Use the map search to examine the available boundaries. For example, searching Iowa reveals options such as Iowa school districts.
  5. Return to the map search, select World, and proceed.
Built-in maps are vector data: Each country is a selectable region rather than a flat image. Datawrapper can connect those regions to rows in your data.
Custom maps come later: The upload option accepts GeoJSON when the built-in maps do not provide the boundaries you need.

Section 2: Upload and match the data

Geographic names in the spreadsheet must match the region identifiers used by the selected map.

Inspect Datawrapper’s region names

The initial data table shows how Datawrapper expects the countries to be identified.

Data matching
  1. Locate the default column named DW name.
  2. Use those entries to understand Datawrapper’s expected country names.
  3. Remember that outside data may use different spellings, abbreviations, or country names.
Names are join keys: A map cannot color a country unless Datawrapper can connect a row in the spreadsheet to the correct geographic feature.

Upload the uncleaned file and inspect errors

Use the first file to see what happens when region names do not match.

Data cleaning
  1. Choose Upload file.
  2. Upload countries.csv.
  3. Look for red indicators beside country names that Datawrapper cannot match.
  4. Click an unmatched name to inspect Datawrapper’s suggested region.
  5. Use the error-checking control to jump between unresolved rows.
Automatic matching is not perfect: Review every suggested match. A close spelling does not guarantee that Datawrapper selected the correct place.

Replace it with the cleaned file

The provided corrected file already uses Datawrapper’s expected country names.

Clean data
  1. Choose Upload file again.
  2. Replace the current sheet with the provided fixed countries file.
  3. Confirm that no country names are marked red.
  4. Check the error count at the bottom of the table.
  5. Choose Visualize.

Section 3: Choose an appropriate measure

A choropleth generally works better with a rate, percentage, or normalized value than with a raw total.

Change population to population density

The initial map displays total population, but totals are often misleading when geographic units differ in size.

Measure
  1. Inspect the first map using total population.
  2. Change the mapped column to population density.
  3. Confirm that the values represent people per square mile.
Normalize the data: Counts such as restaurants, crimes, or people usually rise with population or area. Rates such as restaurants per person or people per square mile allow more meaningful comparison.
Land does not equal people: A map may devote more visual space to a large, sparsely populated region than to a small, densely populated one. Area can visually dominate even when the people represented do not.

Section 4: Refine the color scale

Extreme values can compress the useful differences among most countries.

Make the map zoomable and inspect outliers

Small, extremely dense places explain why the initial population-density scale appears nearly uniform.

Diagnosis
  1. Turn on Make map zoomable.
  2. Zoom into small countries and territories such as Singapore.
  3. Compare their density values with the values for most other countries.
  4. Notice that very high values stretch the scale and leave much of the map in similar light colors.
Do not delete valid outliers just to improve the map: Macau, Monaco, Singapore, and Hong Kong are part of the data. Solve the display problem through the scale rather than by removing inconvenient observations.

Set a custom maximum

Cap the visual scale so that more of the available color range describes the majority of countries.

Color scale
  1. Test stepped and continuous scales to see how each changes the map.
  2. Return to a continuous, linear scale.
  3. Open the custom range controls.
  4. Test a maximum of 800.
  5. Lower the maximum to 500 to create more visible contrast among most countries.
A visual cap groups high values together: Countries above 500 people per square mile will share the darkest color. The legend or surrounding text should communicate that the upper value means 500 or more.
Art direction requires judgment: The goal is not to make the map look dramatic. The goal is to reveal meaningful variation without concealing how the scale works.

Section 5: Add the map’s framing

Use the title, description, source, and alternative description to explain what the map shows.

Add title and source information

The map needs enough attendant text to stand on its own when embedded.

Context
  1. Open the title and annotation settings.
  2. Set the title to World Population Density.
  3. Add a description that states the unit, such as People per square mile.
  4. Add the supplied source name and link.
  5. Write an alternative description explaining that the choropleth shows population density by country.
  6. Leave country labels off if they make the world map too cluttered.
Alternative text should describe the graphic: State the map type, geographic scope, measure, and any major pattern a reader needs in order to understand the content.

Section 6: Customize the tooltips

Use the tooltip to provide useful details beyond the single value encoded by color.

Add density, population, and area

Datawrapper’s tooltip editor accepts data placeholders and basic HTML formatting.

Tooltip
  1. Open the tooltip customization controls.
  2. Keep the region name as the tooltip heading.
  3. Insert the population-density field using Datawrapper’s field button.
  4. Add total population on a new line.
  5. Add total area in square miles on another new line.
  6. Use basic HTML tags to control bold text and line breaks.
<b>Density:</b> {{ density }}
<br>
<b>Total population:</b> {{ population }}
<br>
<b>Total area in square miles:</b> {{ area_sq_mi }}
Use the actual field buttons: The placeholder names depend on the spreadsheet columns. Insert them from Datawrapper rather than copying the example literally.
Format data upstream when necessary: If the tooltip numbers need commas or cleaner labels, edit or format the data columns rather than trying to run JavaScript in the tooltip.

Section 7: Add a text annotation

Use a callout to direct attention to one meaningful pattern or example.

Annotate a country

The annotation should explain why a value matters rather than merely repeat the tooltip.

Callout
  1. Choose Add text annotation.
  2. Place the annotation near the country you want to discuss.
  3. Write one concise sentence interpreting that country’s population density.
  4. Add a line connecting the annotation to the correct location when needed.
  5. Reposition the text so it does not cover important parts of the map.
Use Headline, Highlight, Callout, Context: The title frames the topic, the color highlights the pattern, the annotation calls out an example, and the tooltip provides additional context.

Section 8: Accessibility and all devices

Check whether the map remains understandable without labels, mouse hover, or a wide desktop screen.

Complete the production checks

Interactive maps need both an accessible description and deliberate responsive testing.

5 A’s

A. Accessibility

  • Add an alternative description that explains the map and its measure.
  • Make sure the title and description name the unit.
  • Do not rely on color alone to communicate every important conclusion. Use annotation and text as reinforcement.
  • Confirm that the tooltip information is supplemental rather than essential to understanding the entire map.

B. All devices

  • Test the map at narrow and wide widths.
  • Confirm that zooming and tooltips remain usable on a touch screen.
  • Check whether the annotation stays legible without covering the data.
  • Inspect the published Tilda page rather than relying only on the Datawrapper editor preview.

Section 9: Publish and embed in Tilda

Use Datawrapper’s responsive iframe so the embed can communicate its changing height to the parent page.

Publish from Datawrapper

The responsive embed includes scripts that help the iframe maintain the correct height.

Publish
  1. Choose Publish & Embed.
  2. Select Publish now.
  3. Copy the responsive iframe embed code.
  4. Do not replace it with a basic iframe that uses only a fixed height.
Why the responsive code matters: Datawrapper includes scripts that communicate between the embedded map and the parent page so the iframe can adjust to its content.

Place the embed in Tilda

Wrap the Datawrapper code in a centered container so the map does not become excessively wide.

Embed
  1. Open the assigned Module 4 tutorial page in Tilda.
  2. Add a Custom HTML block.
  3. Create a wrapper with a maximum width of 1160 pixels and automatic horizontal margins.
  4. Paste the complete responsive Datawrapper embed inside the wrapper.
  5. Save and publish the Tilda page.
  6. Open the public page and test the finished map.
<div style="max-width:1160px;margin:0 auto;">
  <!-- Paste the complete responsive Datawrapper embed here. -->
</div>
Art direct the final embed: Check the scale, annotation position, map size, and amount of surrounding space on the real page. The editor preview is not the final production environment.

Submission

Submit the published page after checking the complete embed.

Upload the public URL to your published Tilda page. Do not submit the Datawrapper editor URL or the Tilda editor URL.
