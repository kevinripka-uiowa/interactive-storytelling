Build an Interactive Hotspot Infographic in Genially

In this tutorial, you will use Genially to build an interactive hotspot infographic and then embed it in a Tilda page. The goal is not only to learn where the Genially tools live, but also to practice making decisions when a hosted embed builder gives you some control but not full control.

The example infographic explains wood thrush habits. You will add a background image, create clickable hotspot markers, build pop-up windows with text and media, add alt text, create a mobile version, embed both versions in Tilda, and test the final page on desktop and mobile.

Hosted embed builders are useful, but they still set limits. A hosted embed builder gives you more interactive features than many native blocks, but it is still not the same as writing the code yourself. Genially can make hotspots, windows, videos, and embedded media fairly quickly. It can also create problems with scale, responsiveness, spacing, and media support. Use the builder when it fits the job, but test early so you know where the limits are.

What you will build

An interactive hotspot infographic in Genially, with desktop and mobile versions embedded in a Tilda page. View the finished product example.

What you will submit

The public URL to your published Tilda page, not the Genially editor URL and not the Tilda editor URL.

Before you start

Gather the files, accounts, and project context before opening the builder.

Preparation checklist

Have these pieces ready so the build does not stall while you are inside Genially or Tilda.

Setup
  • Download the Genially hotspot infographic assets from ICON.
  • Open the text file from the asset folder so you can copy and paste the hotspot titles, descriptions, media links, embed codes, and attribution text.
  • Have the desktop background image, mobile background image, food illustration, range map, and any other media files available in the same folder.
  • Log in to Genially and Tilda in separate browser tabs.
  • Know where your Tilda project will place the embed. In this example, the Tilda content grid is 1160 pixels wide, so the desktop Genially canvas is built for that width.

Section 1: Create a blank Genially project

Create a blank Genially project

Step 1
  1. Log in to Genially.
  2. Go to the Content area so you can see your existing projects and create a new one.
  3. Click Create and choose a blank creation.
  4. Wait for the editor to load.
  5. When Genially asks for a size, do not worry about the first preset. You will resize the canvas in the next section.
Use the project dashboard on purpose

Starting from the Content area makes it easier to return to the project later, duplicate it, rename it, and create separate desktop and mobile versions.

Section 2: Set the canvas size

Set the canvas size

Step 2

Before placing content, decide how large the infographic should be when it is embedded in the story page. Do not build first and hope the sizing works later.

  1. In Genially, click Resize.
  2. Choose Custom size.
  3. Turn off Maintain proportions so you can set the exact width and height.
  4. Set the width to 1160 pixels.
  5. Set the height to 870 pixels. This creates a 4:3 canvas for the prepared background image.
  6. Turn Maintain proportions back on after entering the custom size.
  7. Apply the resize setting.
Why 1160 pixels?

In this example, the infographic will sit inside Tilda’s content grid. The full grid is about 1200 pixels wide, with 20 pixels of margin on each side, leaving about 1160 pixels for the actual content. Your number may be different if your story uses a different container or a full-width layout.

Section 3: Add the desktop background image

Add the desktop background image

Step 3
  1. Click Insert.
  2. Choose Image.
  3. Choose Image from device.
  4. Upload the desktop background image, such as background.jpeg.
  5. Resize and position the image so it fills the entire canvas.
  6. Confirm that the image was prepared at a large enough resolution for this canvas.
Do not confuse canvas size with image quality

The Genially canvas controls how the project is laid out. The image file still needs to be large enough to look sharp. Start with a reasonable web image that is at least as large as the display size, and preferably a bit larger.

Section 4: Create the first hotspot window

Create the first hotspot window

Step 4

Genially offers several interactive element types. In this project, the hotspot needs to open a larger content area, so a window works better than a tooltip.

  1. Click Interactive elements.
  2. Review the available options, including Tooltip and Window.
  3. Try Tooltip only long enough to notice the limitation: tooltips are meant for short text and may warn you when the content is too long.
  4. Cancel the tooltip.
  5. Choose Window.
  6. Select a blank window layout so you can build your own structure.
  7. Click Done editing so you can see the clickable marker on the canvas.
  8. Select the marker. If the element is grouped, click again to select the part you need.
  9. Remove placeholder text from the marker if needed.
  10. Resize the marker into a round button.
  11. Change the marker color so it is visible against the background image. In this example, a yellow marker with a black icon works better than a dark marker.
Tooltips are for small reveals

A tooltip is useful for a label, definition, or short note. A window is better when the reader needs a title, paragraph, image, audio embed, video, or attribution. Pick the interactive element based on the amount and type of content, not just the default look.

Section 5: Build the first window content

Build the first window content

Step 5

The first window in this example explains nesting and feeding young. It includes a title, a YouTube video, body text, and video attribution.

  1. Select the hotspot marker.
  2. Click Window to edit the window content.
  3. Unlock the default window objects if needed so you can resize and reposition them.
  4. Make the window large enough to hold the title, video, paragraph text, and attribution.
  5. Add a title text element: Nesting and feeding young.
  6. Reduce the title size so it fits the window. In the tutorial example, a title around 24 points works better than the oversized default.
  7. Make the title bold.
  8. Click Insert, then Video.
  9. Paste the YouTube video link. Genially can use a hosted video link, even if it does not let you upload and host the video file on the free plan.
  10. Resize and position the video inside the window.
  11. Double-click the video and check its settings. Leave autoplay, looping, and similar automatic playback options off unless you have a strong reason to use them.
  12. Paste the body text into a text element.
  13. Adjust the paragraph font size and line spacing so the text is readable. In the example, 16-point body text with more line spacing works better than tightly packed text.
  14. Paste the video credit or source note into a smaller text element.
  15. Center and align the window content so the title, media, body text, and credit feel intentionally placed.
  16. Click Done editing.
  17. Preview the project and click the hotspot to test the window.
Embedding a hosted resource inside a hosted builder

A YouTube video in Genially is a hosted video embedded inside a hosted interactive builder that will later be embedded in Tilda. This is normal, but it is one reason you need to test loading, sizing, and playback on the final published page.

Section 6: Duplicate the hotspot for the other content areas

Duplicate the hotspot for the other content areas

Step 6

After the first hotspot is working, duplicate it rather than rebuilding every marker and window from scratch. This keeps the interaction style more consistent.

  1. Select the completed hotspot marker.
  2. Hold Option and drag the marker to duplicate it.
  3. Move the duplicate to the next location on the background image.
  4. Open the duplicated window and replace the title, text, media, and attribution.
  5. Repeat until the four major content areas are represented.

A. Foraging in leaf litter

  1. Duplicate the hotspot and move it to the foraging area.
  2. Open the window and change the title to Foraging in leaf litter.
  3. Paste the body text from the asset text file.
  4. Insert the food illustration from your device.
  5. Resize the image and arrange it with the text.
  6. Convert dense clue text into a bulleted list if that makes it easier to scan.
  7. Bold the beginning phrase of each bullet or key detail if the list needs stronger hierarchy.
  8. Add the illustration attribution. In the tutorial example, the food illustration is labeled as generated with ChatGPT.

B. Song

  1. Duplicate the hotspot and move it to the singing bird area.
  2. Open the window and change the title to Song.
  3. Paste the song description text.
  4. Try Insert, then Audio, then upload or link the audio source.
  5. If the hosted audio URL does not work as a direct audio upload, use the embed code instead.
  6. Click Insert, then Others.
  7. Paste the audio iframe embed code into the embed field.
  8. Resize and position the embedded audio player as well as Genially allows.
  9. Add the audio attribution below or near the embedded player.

C. Migration

  1. Duplicate the hotspot and move it to the flying bird or migration area.
  2. Open the window and change the title to Migration.
  3. Paste the migration text from the asset file.
  4. Insert the range map image from your device.
  5. Resize the text and map so both remain readable.
  6. If the window becomes crowded, adjust the text size, image size, and spacing before removing content.
  7. Click Done editing and preview the full desktop project.
Use duplication, but still check each item

Duplicating saves time, but it can also carry mistakes forward. After duplicating, check the title, text, media, attribution, marker position, and window layout for each hotspot.

Section 7: Appearance

Appearance

Step 7

Appearance includes the structural design, expressive design, and attendant text. In this project, the Genially file should focus on the interactive graphic itself. The surrounding title, introduction, and source notes can be handled in Tilda.

A. Keep the Genially canvas focused

  1. Use the Genially canvas for the background image, hotspot markers, and window content.
  2. Avoid putting the full story introduction inside Genially if the graphic will be embedded in Tilda.
  3. Plan to add the main heading and explanatory text as normal Tilda text above the embed.

B. Align and size the window content

  1. Use consistent spacing inside each window.
  2. Keep titles visually similar across windows.
  3. Use readable body text rather than trying to fit too much text at a tiny size.
  4. Use lists when the content is easier to scan as separate points.
  5. Keep media credits visible but visually secondary.
Clean is enough here

The goal is not to make the most elaborate Genially project possible. The goal is to make a clear hotspot infographic that supports the story and still works when embedded in another page.

Section 8: Asset optimization

Asset optimization

Step 8

Asset optimization means preparing media so it loads well and looks appropriate on the web. Hosted builders may process some files for you, but you still need to start with sensible assets.

  • Background image: prepare the desktop background for the intended canvas size. In this tutorial, the desktop canvas is 1160 by 870 pixels.
  • Mobile background image: prepare a separate vertical version rather than relying on the desktop image to shrink down.
  • Images inside windows: use files that are large enough to look sharp, but not huge files straight from a camera or design export.
  • Video: use a hosted video link, such as YouTube, rather than uploading a large video file to Genially.
  • Audio: if a direct audio link does not work, use the provider’s iframe embed code when available.
  • Attribution: keep source notes with the media or below the final embed so readers can see where the information and assets came from.

Section 9: Accessibility

Accessibility

Step 9

Accessibility is partly controlled by Genially and partly controlled by you. You cannot inspect or change every underlying HTML decision in a hosted builder, so focus on the accessibility controls the builder gives you and test the published result.

A. Add alt text to images

  1. Select the background image or a media image inside a window.
  2. Open the More menu or the three-dot menu for that image.
  3. Choose Add alt text.
  4. Write a short description of what the image contributes.
  5. Save the alt text.
  6. Repeat for each meaningful image, including the background image, food illustration, and range map.
  • Example: Composited infographic showing four wood thrush behaviors: nesting, foraging, singing, and migration.
  • Example: Illustration of common wood thrush food sources, including beetles, ants, caterpillars, earthworms, spiders, millipedes, and snails.
  • Example: Range map of the wood thrush.
Alt text should serve the content

Do not write alt text as a file name. Write what the image tells the reader. If the image shows habitat, behavior, food sources, or range, say that directly.

B. Check reading order and keyboard access

  1. Use Genially’s accessibility or reading-order tools when they are available.
  2. Preview the project and use the Tab key to see whether the hotspots can receive keyboard focus.
  3. Use Enter or Return to open a focused hotspot if the preview supports keyboard testing.
  4. Test again after embedding and publishing in Tilda, because the final page is what matters.

C. Enable helpful viewer controls

  1. Open the Genially project preferences.
  2. Enable zoom if available.
  3. Enable full screen if available.
  4. Turn off sharing or branding controls that are not needed for the class project.
  5. Preview the project and confirm that the viewer controls appear as expected.

Section 10: Embed the desktop Genially project in Tilda

Embed the desktop Genially project in Tilda

Step 10
  1. In Genially, click Share.
  2. Choose See all or the full sharing options.
  3. Find the iframe embed option.
  4. Copy the iframe embed code.
  5. Go to your Tilda page editor.
  6. Add a new block where the interactive should appear.
  7. Search for HTML or choose the custom HTML block from the Other block category.
  8. Open the block Content panel.
  9. Paste the Genially iframe code.
  10. Save and close the block.
  11. Publish the Tilda page. Tilda usually will not fully preview custom HTML in the editor, so you need to publish to test it.
  12. Open the published page and confirm that the Genially project loads.
Preview is not the same as published

Tilda often requires publishing before custom HTML and iframe embeds can be tested accurately. If you are working on a real live page, create a staging or practice page first, then copy the finished block to the live page.

Section 11: Constrain the desktop embed width

Constrain the desktop embed width

Step 11

The Genially embed may arrive at full width. That can make the interactive larger than the size you designed for. Add a max-width rule to the outer embed wrapper so the desktop version does not stretch beyond 1160 pixels.

  1. Open the Tilda custom HTML block Content panel.
  2. Look for the outer div around the iframe code.
  3. Find the existing width setting, usually width: 100%;.
  4. Add a max-width of 1160 pixels.
  5. Add margin: 0 auto; to center the embed on the page.
  6. Save and close.
  7. Publish again and open the page.
max-width: 1160px;
margin: 0 auto;
What this code does

max-width keeps the embed from becoming wider than the size you designed. margin: 0 auto centers the embed inside the available page width. The iframe can still scale down when the browser is narrower than the max width.

Section 12: Add attendant text in Tilda

Add attendant text in Tilda

Step 12

Because this interactive is embedded in a story page, add the main explanation as normal Tilda text around the embed rather than burying it inside Genially.

  1. Add a simple title/text block above the embed.
  2. Write a clear heading, such as Wood Thrush Habits.
  3. Paste the short introduction that tells the reader what to explore.
  4. Use Settings to align the text with the same content grid as the embed.
  5. Add a small text block below the embed for information and background image attribution.
  6. Reduce the top padding on the attribution block if the gap below the embed is too large.

Section 13: Test the desktop version for responsiveness

Test the desktop version for responsiveness

Step 13
  1. Open the published Tilda page.
  2. Resize the browser window or use the browser’s responsive design mode.
  3. Check the embed at desktop, tablet, and mobile widths.
  4. Open each hotspot window while testing different widths.
  5. Watch for text becoming too small, windows becoming crowded, or media becoming difficult to use.
Genially scales, but scaling is not the same as responsive design

On a small phone screen, a desktop Genially project may simply shrink until the text and buttons are too small. That is not a usable mobile design. If the builder does not reflow the layout, create a separate mobile version.

Section 14: Create a mobile Genially version

Create a mobile Genially version

Step 14

For this example, the desktop version becomes too small on a phone. The solution is to duplicate the Genially project and rebuild the layout for a vertical mobile canvas.

  1. Return to the Genially dashboard.
  2. Find the desktop wood thrush project.
  3. Open the project options and choose Duplicate.
  4. Open the duplicated project for editing.
  5. Rename it so you can tell it is the mobile version, such as Wood Thrush Mobile.
  6. Click Resize and choose a vertical mobile ratio, such as 9:16.
  7. Delete the desktop background image.
  8. Insert the mobile background image from your device.
  9. Use the ordering controls to send the mobile background image to the back.
  10. Move each hotspot marker to the correct location on the mobile image.

Adjust each mobile window

  1. Open the first hotspot window.
  2. Resize the window content for the narrower canvas.
  3. Use larger tap targets for the hotspot buttons.
  4. Keep titles readable, using a consistent title size across windows when possible.
  5. Resize body text for mobile. In the tutorial, 16-point text is more realistic than trying to keep dense desktop text.
  6. Reposition videos, images, audio embeds, body text, and credits for the vertical layout.
  7. Repeat the process for Song, Foraging, and Migration.
Avoid changing the meaning on mobile

Ideally, the mobile version should contain the same information as the desktop version. If the builder makes that impossible, reduce content only as a last resort and recognize that this is a limitation of the tool, not an ideal editorial choice.

Section 15: Embed the mobile version in Tilda

Embed the mobile version in Tilda

Step 15
  1. In the mobile Genially project, click Share.
  2. Copy the iframe embed code.
  3. Return to the Tilda page editor.
  4. Add a second custom HTML block below the desktop embed.
  5. Paste the mobile Genially iframe code into the new block.
  6. Leave the mobile embed width flexible, such as width: 100%, unless you need a specific constraint.
  7. Save and close.

Section 16: Show the right embed on the right device

Show the right embed on the right device

Step 16

The page now has two versions of the same interactive: one desktop version and one mobile version. Use Tilda’s block visibility settings so readers see only the version meant for their screen size.

  1. Open Settings for the desktop Genially embed block.
  2. Find the visibility or device-display controls.
  3. Set the desktop block to show only above 480 pixels.
  4. Open Settings for the mobile Genially embed block.
  5. Set the mobile block to show only below 480 pixels.
  6. Publish the page.
  7. Open the page and resize the browser window to confirm that the desktop version disappears and the mobile version appears at the breakpoint.
Two versions increase maintenance work

A separate mobile version can solve major usability problems, but it also means you now have two interactives to maintain. If you revise the text, media, or attribution later, update both versions.

Section 17: Attribution

Attribution

Step 17

Attribution means explaining where the information and media came from. For this project, some credits may appear inside Genially windows, while broader source notes can appear in Tilda below the embed.

A. Credit information sources

  1. Add a small attribution note below the embed in Tilda.
  2. Credit the source used to summarize the wood thrush information.
  3. Keep the note readable but visually secondary.

B. Credit media sources

  1. Place video and audio credits inside the relevant Genially windows when the media appears there.
  2. Credit the background image below the embed if it applies to the full infographic.
  3. Credit generated images clearly if an image was created with an AI tool.
  4. Repeat attribution work in both the desktop and mobile versions if the same media appears in both.

Section 18: Publish and confirm the final page

Publish and confirm the final page

Step 18
  1. Publish the Tilda page.
  2. Open the published page link, not the editor link.
  3. Refresh the page if needed to confirm the newest version is live.
  4. Test the desktop Genially embed.
  5. Click each hotspot and check the window content.
  6. Test the mobile version by resizing the browser or using responsive design mode.
  7. Confirm that the correct embed appears above and below the mobile breakpoint.
  8. Use the keyboard to check whether the hotspots can be reached and activated.
  9. Confirm that zoom and full-screen controls appear if you enabled them.
  10. Confirm that all visible source notes and media credits are present.
Final check: do not submit the editor URL

Submit the public published page URL. A Tilda editor URL will not work for someone who is grading or viewing your project outside your account.

Submission

What to submit
