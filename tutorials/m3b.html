Build an MLB Hitter Explorer

Which hitters stood out in 2025, and what changes when you define offensive success differently? In this tutorial, you will build an exploratory visualization that lets viewers filter the top 100 hitters by league or team and reorganize them using statistics such as home runs, stolen bases, OPS, OPS+, and WAR.

What you will build

A Flourish Data Explorer that displays one mark for each hitter and gives viewers controls for filtering, changing metrics, and comparing player rankings.

What you will submit

The public URL to the published visualization.

Setup: Understand the data

The dataset contains one row for each of the top 100 hitters from the 2025 season.

1. Download and inspect the CSV

Setup
  1. Download hitters_top_100_cleaned.csv.
  2. Open the file in a spreadsheet application.
  3. Confirm that each row represents one player and each column represents a player characteristic or statistic.
  4. Do not delete the column names in the first row. Flourish will use them when you bind data to visual properties and controls.

The data has already been cleaned Players who appeared for multiple teams have been collapsed into one combined season row. The file contains 100 unique hitters.

Setup: Create the visualization

Use Flourish’s Data Explorer template rather than a standard chart template.

2. Start a Data Explorer

Template
  1. Sign in to Flourish and choose New visualization.
  2. Find and select the Data Explorer template.
  3. Open the Data tab.
  4. Upload hitters_top_100_cleaned.csv and replace the sample data.
  5. Confirm that the imported values align with the correct column headings.
Do not choose the Cards template This lesson uses a data visualization in which each hitter becomes a visual mark. The purpose is to compare distributions and rankings, not to browse profile cards.

Setup: Bind the columns

Tell Flourish which columns identify the hitters and which columns viewers can use to explore them.

3. Assign the essential fields

Data binding

The exact labels in the binding panel may vary slightly as Flourish updates its interface. Use the following plan:

  1. Bind Player as the item label.
  2. Add HR, SB, OPS, OPS+, and WAR as numerical fields that can control position, grouping, or sorting.
  3. Bind Lg as a categorical filter.
  4. Bind Team as a second filter or grouping field.

Build the default view

The opening state should be useful before the viewer touches any controls.

4. Rank hitters by OPS

Default view
  1. Return to the Preview tab.
  2. Choose a one-dimensional grouped or ranked layout rather than a geographic view.
  3. Use OPS as the initial numerical measure.
  4. Arrange or sort the hitters from highest OPS to lowest OPS.
  5. Show player names when the layout remains readable. Otherwise, show names through hover or click.
  6. Limit the amount of overlap by reducing mark size or increasing the visualization height.

Why begin with OPS?

OPS combines a hitter’s ability to reach base with the ability to hit for power. It provides a useful opening view, while the controls allow viewers to challenge that definition of offensive success.

Add filters

Filters let viewers remove irrelevant records and investigate a smaller group of hitters.

5. Filter by league and team

Filter
  1. Open the settings for Controls or Filters.
  2. Turn on the control connected to the Lg field.
  3. Use buttons for the league filter if the choices are only All, AL, and NL.
  4. Turn on the control connected to Team.
  5. Use a dropdown for teams because there are too many choices to display as buttons.
  6. Include an All option so viewers can return to the complete dataset.
  7. Test the filters together. Selecting a league should reduce the available set of teams and hitters.
Filtering changes which hitters are included A filter does not merely recolor the chart. It narrows the dataset so the viewer can ask a more specific question, such as “Who led the National League in OPS?” or “Which Yankees hitter had the highest WAR?”

Add sorting and metric controls

Sorting changes the order of the remaining hitters. A metric control changes what definition of performance is being compared.

6. Let viewers reorganize the hitters

Sort and compare
  1. In the Data Explorer controls, make the numerical measures available as selectable fields.
  2. Include at least OPS, OPS+, HR, SB, and WAR.
  3. Set the arrangement to sort the selected measure in descending order.
  4. When Flourish offers group-order settings, choose descending order so the highest values appear first.
  5. Keep the selected metric visible in the control label or axis title so the viewer always knows what determines the order.
  6. Use ascending order only when a lower value is meaningfully better. None of the five selected measures require ascending order.
Filter and sort answer different questions Filtering asks, “Which hitters should be included?” Sorting asks, “How should those hitters be ordered?” Changing the metric asks, “What characteristic are we using to define the ranking?”

Questions the finished explorer should support

  • Who had the highest OPS among the top 100 hitters?
  • Who led the American League in home runs?
  • Which National League hitters combined power and speed?
  • Which team had multiple hitters near the top in WAR?
  • How different is the ranking by stolen bases from the ranking by OPS?

Build useful popups

The marks should remain visually simple while detailed statistics are available on demand.

7. Add details for each hitter

Details on demand
  1. Open the popup or item-information settings.
  2. Use Player as the popup heading.
  3. Include the team and league directly below the name.
  4. Add the key statistics in a compact order: OPS, OPS+, HR, SB, and WAR.
  5. Add batting average, on-base percentage, and slugging percentage as supporting measures.
  6. Remove fields that do not help viewers interpret the hitter’s performance.

Suggested popup structure

Player name
Team · League
OPS · OPS+ · HR · SB · WAR
BA · OBP · SLG

Do not put every spreadsheet column in the popup Exploration still requires editorial judgment. Include enough information to compare hitters without forcing viewers to scan a statistical record book.

Add a headline and introduction

Exploratory graphics still need framing. Tell viewers what the data contains and what they can do with it.

8. Frame the exploration

Headline and context
  1. Open the settings for the visualization header, title, or text area.
  2. Add the headline below.
  3. Add the introductory paragraph as a subtitle or description.
  4. Add a short instruction near the controls when their purpose is not immediately obvious.

Headline

Explore the top MLB hitters of 2025

Introductory paragraph

Filter the top 100 hitters by league or team, then change the statistic used to arrange them. Compare traditional results such as home runs and stolen bases with broader measures such as OPS, OPS+, and WAR.

Control instruction

Choose a league or team to narrow the field. Select a statistic to change the ranking.

Do not write a conclusion for an exploratory graphic The text should establish the topic, scope, and interaction. It can suggest useful questions, but it should leave room for viewers to make their own comparisons.

Refine the appearance

Create a clear visual hierarchy without overwhelming the data with baseball decoration.

9. Apply the 5 A’s

Production
Appearance Use one restrained color for marks or a limited palette for league or team. Keep the background, labels, and controls simple.
Asset optimization The project uses no large images. Avoid decorative media that increases loading time without improving the comparison.
All devices Preview the visualization at desktop and phone widths. Make sure controls wrap cleanly and player labels remain usable.
Accessibility Do not rely only on color to distinguish leagues or teams. Include text labels, readable controls, and a useful alternative description.
Attribution Add a source line identifying the baseball statistics source and note that the file contains the tutorial’s selected top 100 hitters.
Number formatting Show BA, OBP, SLG, and OPS to three decimal places. Show counting statistics as whole numbers and WAR to one decimal place.

Test the exploration

Use the finished visualization as a viewer would and confirm that every control produces a meaningful state.

10. Complete a final check

Testing
  1. Reset all filters and confirm that the visualization begins with all 100 hitters.
  2. Filter to the American League and then the National League.
  3. Select several teams, including a combined 2TM entry if Flourish presents it as a filter value.
  4. Switch among OPS, OPS+, HR, SB, and WAR.
  5. Confirm that the order changes when the selected metric changes.
  6. Hover over or select several hitters and check the popup values.
  7. Test the visualization at a narrow mobile width.
  8. Use the keyboard to reach the controls and inspect whether focus is visible.
Check the combined-team category Players who changed teams during the season use values such as 2TM. You may leave this as a valid category, rename it “Multiple teams” in the CSV, or exclude it from the team filter if that produces a clearer experience.

Publish and submit

Publish the visualization only after the default view and all exploratory controls have been tested.

11. Finish the project

Deliverable
  1. Add a source note and alternative description.
  2. Publish the visualization.
  3. Open the public URL in a new tab and test it again.
  4. Republish after making any later changes.
  5. Submit the public Flourish URL.

Required features

  • A headline and introductory paragraph or subtitle.
  • One visual mark for each hitter in the current filtered set.
  • A league filter.
  • A team filter.
  • At least five selectable performance measures.
  • Descending sorting based on the selected measure.
  • Player details available through hover, click, or another details-on-demand interaction.
  • A source note and alternative description.
