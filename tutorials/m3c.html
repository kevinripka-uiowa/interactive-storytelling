Tutorial M3 - C

Build Interactive Timelines with JavaScript Libraries

In this tutorial, you will build two interactive timelines from existing code libraries. The timeline is the product, but the larger goal is learning how to evaluate documentation, load dependencies, copy the required structure, configure a plugin, and adapt it to your own content.

A library gives you a head start, not a finished project. It supplies reusable code and expected patterns. You still need to understand the required files, markup, initialization code, configuration options, data structure, and CSS.

What you will build

Two timelines: a Squarechip timeline built from HTML markup and a jQuery Albe Timeline built from an array of JavaScript objects.

What you will submit

A ZIP file containing the complete project folder with both HTML files and any supporting assets.

Set up a local project and gather the supplied tutorial assets.

Prepare the project folder

You will work locally in VS Code and preview the pages with Live Server.

Setup
  1. Download the Module 3C assets from ICON.
  2. Create a new project folder. A name such as timeline-libraries is appropriate.
  3. Open the folder in VS Code.
  4. Create two HTML files: squarechip.html and albe.html.
  5. Add a basic HTML5 page wrapper to each file.
  6. Start Live Server so you can inspect changes as you work.
Keep the whole project together: You will submit the folder as a ZIP file rather than embedding these timelines in Tilda.

How to approach an unfamiliar library

Documentation is the map. Read it in a predictable order rather than copying random code.

Evaluate the library before building

A timeline library may save time, but only if its capabilities and maintenance level fit your project.

Library literacy
  1. Open the library’s demo and confirm that the interaction matches what you want.
  2. Find the required CSS and JavaScript files.
  3. Check whether the files are available through a CDN or must be downloaded.
  4. Find the required HTML markup or data structure.
  5. Find the initialization code that activates the library.
  6. Review the configuration options and note any dependencies.
  7. Check how recently the project has been maintained and expect more troubleshooting with older libraries.
Builders are usually easier: A Flourish timeline may be the practical choice for a real project. This exercise uses libraries so you can understand what builders normally handle for you.

Timeline 1: Set up Squarechip Timeline

The first library uses ordinary HTML markup and plain JavaScript.

Load the library files

Use the CDN links supplied in the tutorial assets.

Dependencies
  1. Open squarechip.html.
  2. Open the Squarechip documentation and demo links from the assets folder.
  3. Find the library stylesheet URL in asset-links.txt.
  4. Add it with a stylesheet link.
  5. Find the minified JavaScript library URL and add it near the end of the body.
<link rel="stylesheet" href="PASTE-CSS-CDN-URL-HERE">

<script src="PASTE-JAVASCRIPT-CDN-URL-HERE"></script>
Why a CDN? A content delivery network hosts commonly used files online. It avoids copying the library into your project, although a locally downloaded copy gives you more control and does not depend on a third-party host.

Timeline 1: Add the required markup

This library expects a specific nested HTML structure.

Copy the documented HTML pattern

The class names connect your HTML to the library’s CSS and JavaScript.

Markup
  1. Find the HTML markup example in the Squarechip documentation.
  2. Copy the timeline wrapper, timeline container, and sample timeline items into the body.
  3. Save and inspect the page. It should begin to resemble a timeline even before initialization.
  4. Notice that the library controls the timeline structure, but the content inside each item is still ordinary HTML that you can edit.
<div class="timeline">
  <div class="timeline__wrap">
    <div class="timeline__items">
      <div class="timeline__item">
        <div class="timeline__content">
          <h3>Timeline event</h3>
          <p>Event description.</p>
        </div>
      </div>
    </div>
  </div>
</div>

Timeline 1: Initialize and configure the library

Loading a library does not activate it. You must call its function after the library has loaded.

Create the timeline instance

The first argument identifies the timeline element. The second is a configuration object.

JavaScript
  1. Add a new script block after the library script.
  2. Call the library’s timeline() function.
  3. Use document.querySelectorAll('.timeline') to select the timeline.
  4. Add a configuration object with curly braces.
  5. Set the mode to horizontal, show three items at a time, and switch to vertical mode below 800 pixels.
<script>
  timeline(document.querySelectorAll('.timeline'), {
    mode: 'horizontal',
    visibleItems: 3,
    forceVerticalMode: 800
  });
</script>

Reading a configuration object

  • An object is enclosed in curly braces.
  • Each setting uses a key: value pair.
  • Text values require quotation marks.
  • Numbers do not use quotation marks.
  • Boolean values use the keywords true or false.
  • Separate settings with commas and copy the documented key names exactly.
Responsive behavior: forceVerticalMode: 800 tells the horizontal timeline to become vertical when the viewport is narrower than 800 pixels.

Timeline 2: Set up jQuery Albe Timeline

The second timeline is a jQuery plugin and uses JavaScript data rather than repeated HTML markup.

Load dependencies and recover missing CSS

This older plugin requires more investigation because its documentation and hosted files are incomplete.

Troubleshooting
  1. Open albe.html and the two documentation links supplied in the assets.
  2. Add jQuery before the Albe Timeline plugin script. The plugin depends on jQuery and cannot run first.
  3. Add the hosted Albe Timeline JavaScript URL from asset-links.txt.
  4. Test the documented stylesheet URL. When it fails, open the library’s GitHub repository.
  5. Find the horizontal timeline template and open its raw CSS file.
  6. Copy that CSS into a style block in your page.
  7. Remove broad rules that style body or other global elements if they could interfere with the rest of a page.
<script src="JQUERY-CDN-URL"></script>
<script src="ALBE-TIMELINE-CDN-URL"></script>

<style>
  /* Paste the timeline template CSS here. */
</style>
Scope imported styles: Older examples may include page-wide styling. Remove or rewrite global selectors before placing the code inside a larger website.

Timeline 2: Create an array of event objects

Albe Timeline generates the markup from structured JavaScript data.

Understand arrays and objects

An array is an ordered list. Each item in this array is an object representing one timeline event.

Data structure
  1. Create a script block.
  2. Declare a constant named timelineData.
  3. Assign it an array using square brackets.
  4. Copy one sample event object from the documentation into the array.
<script>
  const timelineData = [
    {
      time: '2015-04-30',
      body: [
        { tag: 'h2', content: 'Sample event' },
        { tag: 'p', content: 'Sample description' }
      ]
    }
  ];
</script>

How the structure nests

  • timelineData is an array because events must remain in order.
  • Each event is an object enclosed in curly braces.
  • The event’s body is another array.
  • Each body item is another object describing an HTML tag and its content or attributes.

Timeline 2: Add the target element and initialize the plugin

The plugin needs one HTML container and a jQuery call that passes in your data.

Connect the data to the page

The selector, method, and variable name must agree with your own code.

jQuery
  1. Add a div with the ID myTimeline.
  2. Add a jQuery document-ready function after timelineData.
  3. Select the div with $('#myTimeline').
  4. Call the albeTimeline() method and pass in timelineData.
<div id="myTimeline"></div>

<script>
  $(document).ready(function () {
    $('#myTimeline').albeTimeline(timelineData);
  });
</script>
Why the document-ready function? It waits until the page markup is available before jQuery tries to find and transform the timeline div.

Timeline 2: Format dates and set the language

The plugin defaults to Brazilian Portuguese and requires a manual language definition.

Configure month-year dates in English

This step illustrates a common problem with older or incomplete plugins: documented options may require extra setup.

Configuration
  1. Add a second argument to albeTimeline(): a configuration object.
  2. Set formatDate to the documented month-year pattern.
  3. Set the language to U.S. English.
  4. When the month remains in Portuguese, use the documentation’s language override method.
  5. Copy only the English language definition and place it before the timeline initialization.
$(document).ready(function () {
  /* Paste the documented English language definition here. */

  $('#myTimeline').albeTimeline(timelineData, {
    formatDate: 'MMM YYYY',
    language: 'en-US'
  });
});
Documentation may be incomplete: Setting a language code does not work unless that language has actually been defined for the plugin.

Timeline 2: Build one complete event object

Construct one event manually so you understand the supplied data file before replacing it.

Create semantic content from object properties

Each body object tells the plugin which HTML tag to create, what content to insert, and which attributes to add.

Objects

A. Add an event chip

{
  tag: 'p',
  content: 'Loss',
  attr: {
    cssclass: 'tl-chip tl-chip-loss'
  }
}

B. Add the displayed date

{
  tag: 'time',
  content: 'September 1, 1914',
  attr: {
    cssclass: 'tl-date'
  }
}

C. Add an accessible image

{
  tag: 'img',
  attr: {
    src: 'IMAGE-URL-HERE',
    alt: 'Martha, the last known passenger pigeon'
  }
}

D. Add the title and description

{
  tag: 'h2',
  content: 'Extinction of the passenger pigeon'
},
{
  tag: 'p',
  content: 'Your event description goes here.'
}
Escape quotation marks inside strings: A quotation mark that belongs inside quoted text must be preceded by a backslash, such as \"quoted words\". Otherwise, JavaScript interprets it as the end of the string.

Timeline 2: Finish the data and add animation

Replace the practice event with the supplied complete dataset, then add the optional Animate.css dependency.

Complete and enhance the timeline

This final stage also demonstrates dependency-version conflicts.

Integration
  1. Open the supplied complete timeline data file.
  2. Replace your practice timelineData constant with the full array.
  3. Confirm that the variable name remains timelineData everywhere.
  4. Add the supplied custom CSS and remove any global selectors that could affect the surrounding page.
  5. Open Animate.css and add its stylesheet CDN link.
  6. Add an effect setting to the Albe Timeline configuration object.
  7. Choose an entrance effect such as jackInTheBox.
  8. When the effect fails, replace the current Animate.css URL with version 3.7.2.
  9. Use the older, non-namespaced class name expected by the plugin.
<link rel="stylesheet" href="ANIMATE-CSS-3.7.2-CDN-URL">

<script>
  $(document).ready(function () {
    $('#myTimeline').albeTimeline(timelineData, {
      formatDate: 'MMM YYYY',
      language: 'en-US',
      effect: 'jackInTheBox'
    });
  });
</script>
Version compatibility matters: Animate.css 4 introduced namespaced class names. This older plugin expects the version 3 naming pattern, so the newest dependency is not automatically the correct dependency.
Use motion deliberately: The demonstration effect is intentionally conspicuous. For a real project, choose subtle motion that supports orientation rather than competing with the content.

Production checks

Before submitting, verify the code, content, accessibility, and folder structure.

Review both timelines

A library can handle the mechanics, but you remain responsible for the final experience.

5 A's

Appearance

  • Check hierarchy, spacing, image scale, and line length.
  • Make sure custom CSS overrides only what you intend.
  • Use restrained animation.

Asset optimization

  • Use appropriately sized images rather than unnecessarily large files.
  • Keep only the files the project actually needs.

All devices

  • Resize the browser and test both timelines at narrow widths.
  • Confirm that the Squarechip timeline switches to vertical mode.
  • Check whether images, labels, and event text remain readable.

Accessibility

  • Give every meaningful image useful alt text.
  • Use semantic tags such as headings, paragraphs, and time.
  • Do not rely on color alone for event categories.
  • Confirm that animation does not obscure content or make it difficult to read.

Attribution

  • Credit the timeline information and any images that require attribution.
  • Retain notices required by the libraries’ licenses.
