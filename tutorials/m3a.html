Build an Explanatory Data Visualization

You will begin with a crowded chart of European unemployment rates and turn it into a clear explanation about Bosnia and Herzegovina, Greece, and the years following the 2008 financial crisis.

The final chart will use a four-part explanatory method: Headline, Highlight, Callout, Context.

HeadlineState the chart’s main claim.
HighlightMake the important data visually dominant.
CalloutPoint to a specific value or change.
ContextKeep enough surrounding data to make the claim meaningful.

Setup: Add the data

Start by creating a new chart and checking that Datawrapper has interpreted the spreadsheet correctly.

1. Upload and check the dataset

Setup
  1. In Datawrapper, select Create New, then Chart.
  2. Use the XLS/CSV upload option and select europe_unemployment.csv from ICON.
  3. In Check & Describe, confirm that the first row contains column names and that the data types are correct.
  4. Fix any errors before proceeding.
Data type colors Red indicates an error. Blue indicates numbers. Black indicates text. Green indicates dates.

Setup: Choose and orient the chart

The data should become a line chart with years across the horizontal axis and countries represented as separate lines.

2. Select a line chart and transpose the data

Setup
  1. Proceed to Visualize.
  2. Select the Lines chart type.
  3. Check the horizontal axis. If countries appear across the bottom, the data is oriented incorrectly.
  4. Select Transpose the data so years appear on the horizontal axis and each country becomes a separate line.
The chart will now look worse before it looks better A chart with many overlapping lines is often called a spaghetti chart. The solution is not necessarily to remove the surrounding data. Instead, use visual hierarchy to separate the main story from its context.

Setup: Create a neutral baseline

Before emphasizing the story, reduce the visual weight of everything.

3. Deemphasize all country lines

Setup
  1. Open the Refine tab.
  2. In Customize lines, select All.
  3. Change every line to a light gray.
  4. Turn off labels next to the lines. Viewers can identify the background lines through tooltips.
  5. For the horizontal axis, use ticks instead of full gridlines to reduce clutter.
Why change the individual lines? A global gray palette may still assign several different gray values. Selecting all lines in Customize lines gives the background series one consistent visual treatment.

Headline

The headline should tell viewers what the chart is about, not merely name the variables.

4. Write a claim-driven title

Headline
  1. Open the Annotate tab.
  2. Replace the default title with a headline that frames the intended story.
  3. Add a short description only when the title needs context or definitions.

Working headline

Balkan unemployment remained unusually high after the financial crisis

Avoid a label-only title “Balkan Unemployment” identifies the topic, but it does not tell viewers what they should learn from the chart.

Highlight

Use contrast to show which lines carry the central comparison.

5. Emphasize Bosnia and Herzegovina and Greece

Highlight
  1. In Customize lines, select None to clear the current selection.
  2. Select only Bosnia and Herzegovina.
  3. Give the line a strong accent color, increase its width, and display its label as a legend.
  4. Select Greece and apply the same treatment with a second distinct color.
  5. Leave the remaining countries thin and light gray.
Use emphasis selectively The two highlighted lines should be dominant immediately. The other countries should remain visible but clearly secondary.

Callout

A callout points viewers to a specific value, peak, or change that supports the headline.

6. Annotate the Bosnia and Herzegovina peak

Callout
  1. In the Annotate tab, select Add text annotation.
  2. Click and drag near the peak in the Bosnia and Herzegovina line.
  3. Write a short explanation of what the peak represents.
  4. Turn on the line connecting the annotation to the data.
  5. Add a circle at the end of the line so the exact point is clear.
  6. Adjust the curve, position, and width so the annotation does not cover the data.
Write the meaning, not the obvious Avoid annotations such as “highest point.” Explain why the peak matters or what was happening at that time.

Context

Context helps viewers understand the highlighted lines in relation to the rest of Europe and to a meaningful period in time.

7. Preserve comparison and mark the crisis period

Context

Other countries

Keep the other European countries as light-gray lines. They establish the typical range and show why the highlighted countries stand out.

Time period

Use the range-highlighting tool to shade approximately 2008 through 2013.

Add a short label identifying the period after the 2008 financial crisis.

Axes and scale

Keep enough year labels to make the timing clear. Increase the chart width if Datawrapper removes too many labels.

For this version, use approximately 800 pixels wide and a plot height near 400 pixels.

Source and notes

Add a source line and any definition needed to understand what the unemployment rate measures.

Context is not decoration Every background line, shaded range, axis label, and source note should help viewers judge the claim.

Accessibility and layout

Make the chart understandable without relying only on color or hover interaction.

8. Complete the explanatory graphic

Production
Alternative description Describe the main pattern, the two highlighted countries, and the importance of the post-2008 period.
Direct identification Use legend labels, annotations, or text so color is not the only way to identify the important lines.
Readable layout Confirm that the headline, annotation, labels, and highlighted range do not overlap.
Responsive preview Check the chart at several widths. Reduce annotation text or adjust plot height if the mobile version becomes crowded.

Publish and export

Review the layout, then create the version needed for your project.

9. Finish the chart

Output
  1. Review the Layout options.
  2. Turn off data downloading when it is not appropriate for the project.
  3. Proceed to Publish & Embed.
  4. For an online project, publish and use the embed code or public URL.
  5. For a static assignment, export a PNG or JPG using the option available to your account.

Submission checklist

Your chart should demonstrate all four parts of the explanatory method.

What the finished graphic must include

Deliverable
  • Headline: A title that states the main claim.
  • Highlight: Bosnia and Herzegovina and Greece clearly emphasized against neutral background lines.
  • Callout: At least one annotation connected to a specific data point.
  • Context: Other European countries, a highlighted time range, readable axes, and a source note.
  • An alternative description for screen-reader users.
  • A published link, embed, or exported image as required by the assignment.
