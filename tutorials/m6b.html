Annotate a Northern Flicker in Sketchfab

Use a 3D model to explain how the Northern Flicker’s body supports its unusual behavior and how its appearance varies across North America.

The annotation sequence should work as a short guided tour. Each marker needs a meaningful location, a composed camera view, and concise explanatory text. The order should move viewers through the bird rather than feel random.

What you will build

An embedded Sketchfab model with an intentional initial view and four annotations: bill, tail, underwing color, and spotted plumage.

What you will practice

Setting a camera and pivot, placing annotation markers, saving a distinct view for each annotation, using Markdown to add an image, ordering a guided sequence, and embedding the model in Tilda.

Video walkthrough

Watch the complete process, then use the written steps below as a reference while you work.

Before you start

Prepare the model, account, and image needed for the annotation sequence.

Preparation checklist

Setup
  • Sign in to Sketchfab.
  • Download the supplied Northern Flicker model files from ICON.

Section 1: Upload and credit the model

Upload the supplied files, add the source credit, and open the model in Sketchfab’s 3D Editor.

Create the model page

Step 1
  1. Sign in to Sketchfab and choose Upload.
  2. Select the supplied Northern Flicker model files. If the download contains several related files, upload them together.
  3. Give the model a clear title: Northern Flicker.
  4. Add the model attribution to the description. Sketchfab accepts Markdown, so the creator and source can be linked.
  5. Save the draft, then choose Edit 3D Settings.

Attribution for the model description

3D model: [Northern Flicker](https://sketchfab.com/3d-models/northern-flicker-c1ce69a0b2974f729445eff31f8f4423) by [RISD Nature Lab](https://sketchfab.com/RISDNaturelab), licensed under Creative Commons Attribution.
Keep the model in draft while you work

You can edit the model before publishing it. Publish only after the initial view, presentation settings, and annotations are complete.

Section 2: Set the initial view

The opening camera position should introduce the complete bird before the annotation sequence begins.

Compose and save the opening view

Step 2
  1. Rotate the model to a three-quarter view that shows the head, patterned body, folded wing, and tail.
  2. Zoom so the entire bird fits comfortably in the viewer without large empty areas.
  3. Test the pivot by rotating slightly. The model should stay centered instead of swinging out of frame.
  4. Choose Save View to save the opening camera position and thumbnail.
Initial view versus annotation view

The initial view introduces the whole object. Each annotation view should move closer and reframe the model around one specific feature.

Section 3: Explore the presentation settings

Use the 3D Editor to make the model clear and believable, but do not spend the class trying to master every advanced material control.

Make restrained visual adjustments

Step 3
  1. Explore the Scene, Lighting, Materials, Background, and Post-processing panels.
  2. Try a few lighting environments and background colors. Choose settings that separate the bird from the background and preserve feather detail.
  3. Keep Lit rendering unless the model’s textures already contain baked lighting. Shadeless rendering removes lighting and shadows.
  4. Avoid making feathers look metallic or highly glossy. Use restrained material changes that suit a taxidermy bird.
  5. Check the model from several angles before settling on the settings.

Lighting

Sketchfab recommends Lit mode for most models. Environmental lighting and shadows are enabled by default, and the lighting environment can be rotated or adjusted.

Orientation and pivot

The bird should be upright, rest sensibly in the scene, and rotate around a useful center rather than swinging out of view.

Explore, then make a decision

The goal is not to use every effect. The goal is a neutral, legible presentation in which the bill, tail, underwings, and plumage patterns remain easy to inspect.

Section 4: Annotation 1 — The bill

Begin at the head because the bill immediately introduces how the flicker differs from many other woodpeckers.

Place the marker and save the view

Annotation 1
  1. Open the Annotations panel.
  2. Rotate and zoom to create a close three-quarter view of the head and bill.
  3. Place the annotation marker directly on the bill.
  4. Add the title and description below.
  5. Use the camera or save-view control for this annotation to record the current camera position.

Title

A bill built for digging

Description

Unlike the straight, chisel-like bills of many woodpeckers, the Northern Flicker has a slightly downcurved bill. Flickers use it to probe and dig in soil for ants and beetles, then collect prey with a long, barbed tongue.

Section 5: Annotation 2 — The tail

Move from the head to the rear of the bird and explain a structural feature shared with other woodpeckers.

Show the stiff tail feathers

Annotation 2
  1. Rotate the model so the tail is clearly separated from the folded wings.
  2. Zoom close enough to show the pointed tail feathers without cropping away all body context.
  3. Place the marker on the center of the tail.
  4. Add the title and description below.
  5. Save this camera position as the annotation view.

Title

A built-in brace

Description

Woodpeckers have stiff central tail feathers that can press against a tree trunk and help support the body while climbing or hammering. Northern Flickers often feed on the ground, but they retain this woodpecker adaptation.

Section 6: Annotation 3 — Yellow-shafted and red-shafted forms

Use the underwing color to compare the eastern and western forms of the same species.

Add an image with Markdown

Annotation 3
  1. Rotate the bird so the yellow underside of the wing is visible.
  2. Frame the view to emphasize the colored flight-feather shafts while keeping enough of the bird visible for orientation.
  3. Place the marker on the yellow area beneath the wing.
  4. Paste the Markdown below into the annotation description.
  5. Save the current camera position for the annotation.

Title

Yellow in the East, red in the West

Description with image

The model shows a **Yellow-shafted Northern Flicker**, the form found across eastern North America. Its flight and tail feathers flash yellow from below. In western North America, **Red-shafted Northern Flickers** show rosy red or salmon-colored shafts instead.

Check the preview

Confirm that the image loads inside the annotation and that the description remains readable. If the image dominates the panel, use a smaller Wikimedia thumbnail URL.

Section 7: Annotation 4 — Spots and bars

End with a whole-body pattern that connects appearance to the bird’s ground-foraging behavior.

Reframe the patterned body

Annotation 4
  1. Rotate the model to show the spotted belly and barred back or wing.
  2. Pull back slightly so viewers can see the pattern across a larger part of the bird.
  3. Place the marker on the spotted belly or the transition between the spots and bars.
  4. Use the exact description below.
  5. Save this camera position for the annotation.

Title

Patterned for the ground

Description

Unlike most woodpeckers, northern flickers spend a large amount of time searching for ants and beetles on the open ground, where the spotted and barred pattern helps them vanish against grass, dirt, and leaf litter.

Section 8: Order and test the guided sequence

The annotation list determines the path viewers follow through the model.

Arrange the annotations

Step 8
  1. Drag the annotations into this order: bill, tail, color forms, spots and bars.
  2. Start from the saved initial view.
  3. Select Annotation 1 and confirm that the camera moves to the bill.
  4. Advance through all four annotations and check every camera composition.
  5. Make sure no marker blocks an important feature or becomes hidden inside the model.
  6. Confirm that the red-shafted flicker image loads and its credit is visible.
  7. Save the model settings.

Good camera movement

Each step changes the viewer’s attention without becoming disorienting. The feature remains centered and large enough to inspect.

Weak camera movement

Several annotations use nearly identical views, the camera lands too far away, or the model rotates so dramatically that viewers lose orientation.

Section 9: Publish and embed the model in Tilda

Use Sketchfab’s embed code inside a T123 HTML block.

Publish, copy, and place the embed

Step 9
  1. Save the 3D settings and publish the model.
  2. Open the published model page and choose Embed.
  3. Keep the annotation controls visible and copy the complete embed code.
  4. Add a T123 HTML block to your Tilda page and paste the embed code.
  5. Add the CSS below inside the same T123 block. Sketchfab’s embed includes a wrapper named sketchfab-embed-wrapper.
  6. Publish the Tilda page before testing the embed.

Section 10: Add context outside the model

A 3D viewer is highly visual and may be difficult for some people to navigate. The surrounding page should preserve the essential information.

Build an accessible presentation

Final check
  • Add a clear headline above the embed.
  • Write a short introduction explaining what the model shows and how to rotate, zoom, and select annotations.
  • Provide a text summary of the four annotated features below the embed.
  • Credit the 3D model creator and license.
  • Credit the red-shafted flicker photograph as Tom Koerner/USFWS.
  • Test the page with keyboard navigation and at mobile width.
  • Confirm that all annotation text is concise enough to read inside the viewer.
