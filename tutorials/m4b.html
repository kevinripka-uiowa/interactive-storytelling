Tutorial M4 - B

Build a Slippy Locator Map in Flourish

In this tutorial, you will build a tiled locator map of birding destinations in Johnson County, Iowa. You will import point locations, add a county boundary from GeoJSON, create an inset map, customize popups, constrain the pan-and-zoom area, and embed the finished map in Tilda.

A slippy map is built for exploration. Instead of showing one fixed map view, it loads map tiles as the reader pans and zooms. That added agency also creates more production decisions about bounds, zoom levels, labels, and interaction.

What you will build

An interactive locator map with birding destinations, custom location markers, a highlighted Johnson County boundary, an inset map, and custom popups.

What you will submit

The public URL to the published Tilda page containing your embedded Flourish map.

Video walkthrough

Purpose and tool choice

Choose a map builder according to the interaction and geographic marks the project requires.

Why use Flourish for this locator map?

This project needs a true pan-and-zoom map rather than a fixed locator map.

Tool choice
  • The map needs point locations for birding destinations.
  • The reader should be able to pan and zoom.
  • The map should include a county region for geographic context.
  • The map should display custom popups for each location.
  • An inset map should show where the main view sits within the county.
Flourish handles most locator-map needs quickly: A custom Leaflet map would offer more control, but Flourish can produce this type of project with much less code.
Datawrapper is still useful: Its locator maps can be visually polished, but they are better suited to fixed or mostly static locator graphics than to full slippy-map interaction.

Section 1: Create the map

Start with the Flourish marker-map template that supports custom popup content.

Open the correct template

Flourish includes many projection, 3D, and marker-map templates. This project needs the marker map with editable popups.

Setup
  1. Log in to Flourish.
  2. Choose New visualization.
  3. Ignore the projection-map and 3D-map templates for this project.
  4. Select the Marker map with custom popups template.
  5. Rename the project Locator Map rather than leaving the default unnamed title.

Review the data sheets

The template begins with several sheets that control different map layers.

Data structure
  • Locations: Point features such as parks and birding destinations.
  • Categories: Optional marker categories or icon groups.
  • Regions: Polygon features drawn on the main map.
  • Inset map regions: Polygon features shown in the inset map.
Delete unused structure: Remove the Categories sheet because this tutorial uses one marker style for every destination.

Section 2: Import the point locations

Upload the birding-destination data and assign the fields Flourish needs to position and describe each marker.

Upload birds.csv

The location sheet needs names, coordinates, and fields for the popup content.

Locations
  1. Open the Locations sheet.
  2. Upload birds.csv from the course downloads.
  3. Import the file and assign the columns.
  4. Set the name field to column A.
  5. Set latitude to column B.
  6. Set longitude to column C.
  7. Leave marker and photo fields blank because the spreadsheet does not provide them.
  8. Assign columns A, D, and E as the information fields available to the popups.
Clear unused bindings: Do not leave placeholder columns assigned to fields your data does not contain. Incorrect bindings can create missing or broken output.

Refresh if the map does not move to the data

The template may fail to update its initial view immediately after import.

Troubleshooting
  1. Switch to Preview.
  2. Confirm that the initial viewport is set to Auto.
  3. If the points do not appear, refresh the Flourish editor page.
  4. Return to Preview and confirm that the map now frames the imported locations.
This is an editor glitch, not a data problem: Auto viewport should fit all points, but the editor may need a refresh before recalculating the view.

Section 3: Style the basemap

The basemap provides roads, towns, boundaries, water, and other geographic context beneath your own data layers.

Use vector tiles and select OSM Bright

Vector tiles allow Flourish to restyle individual basemap layers.

Basemap
  1. Open the Basemap settings.
  2. Keep the map tile type set to Vector.
  3. Change the basemap style to OSM Bright.
  4. Leave the remaining basemap settings unchanged for now.
Vector tiles are styled map components: Unlike one flattened raster image, vector tiles allow the builder to turn labels, roads, borders, and other layers on or off.

Section 4: Add custom markers

Use one default marker image for every birding destination.

Upload the location icon

The marker does not need to come from the spreadsheet when every location uses the same visual symbol.

Markers
  1. Open the Markers settings.
  2. Use the default marker-style controls rather than assigning a marker from the data.
  3. Upload location.png.
  4. Increase the marker scale to approximately 3.
  5. Preview the map and confirm that each destination uses the custom icon.
Scale is contextual: The marker should remain visible at the starting zoom level without becoming so large that nearby destinations overlap excessively.

Section 5: Add the Johnson County region

Upload a GeoJSON polygon to show the county boundary and distinguish it from the basemap.

Import the county GeoJSON

The Regions sheet accepts geometry and optional data used to style or describe each feature.

GeoJSON
  1. Open the Regions sheet.
  2. Upload Johnson County.geojson.
  3. Assign the geometry field to column A.
  4. Assign any available numeric field as the required value. The tutorial does not use that value visually.
  5. Assign the county name as the category field so it can control the region style.
  6. Leave popup information blank because the county polygon will not use a popup.
Geometry carries the shape: The GeoJSON stores the county boundary as coordinates. Its property fields can also supply names, categories, values, and popup content.

Style the county region

Use the settings document supplied with the tutorial for the county fill color.

Region styling
  1. Return to Preview and open the Regions settings.
  2. Locate the category created from the county name.
  3. Apply the semi-transparent green county color from settings.txt.
  4. Turn off region outlines.
  5. Preview the result and confirm that the county remains visible without overpowering the point locations.
Use transparency for context layers: The region should orient the reader while still allowing roads, towns, and markers beneath or above it to remain legible.

Customize the basemap layers

Remove unnecessary linework while preserving useful town labels.

Layer styling
  1. Open Customize basemap, then Customize layers.
  2. Turn off basemap borders.
  3. Turn on labels.
  4. Confirm that towns such as North Liberty and Solon remain visible.
Basemap hierarchy matters: Keep only the geographic context that helps readers locate the destinations. Extra boundaries and linework compete with your own region and markers.

Section 6: Add the inset map

An inset map shows the main map’s location within a broader geographic area.

Reuse the county geometry

The inset map can use the same Johnson County polygon as the main region layer.

Inset map
  1. Open the Inset map regions sheet.
  2. Upload the same Johnson County.geojson file.
  3. Assign the geometry field to column A.
  4. Return to Preview.
  5. Open the Inset map settings.
  6. Turn on Display map.
The inset explains spatial context: It shows where the current view sits in relation to Johnson County, especially after the reader pans or zooms.

Section 7: Add title, instructions, and source

Frame the map so readers know what it shows and how to use it.

Add the header and footer

The map should explain both its subject and its interaction.

Context
  1. Open the Header settings.
  2. Set the title to Top Birding Destinations in Johnson County, Iowa.
  3. Add brief instructional text such as Pan and zoom to explore.
  4. Open the Footer settings.
  5. Add eBird as the source name.
  6. Add the eBird source URL supplied with the tutorial materials.
Instructional text is part of the interface: A short phrase can make the available agency obvious without forcing readers to discover it by accident.

Section 8: Customize the popups

Build popup content from the fields imported with each location.

Set the popup heading

The custom-popup template uses double curly brackets to insert values from the spreadsheet.

Templating
  1. Open Popups and panels.
  2. Replace the sample popup heading with the location-name field.
  3. Use the exact capitalization of the spreadsheet column name.
  4. Change the header style from inline to Block.
{{ name }}
Handlebars-style placeholders connect data to layout: Flourish replaces each placeholder with the value from the selected location’s row.

Build the main popup content

Use basic HTML to create a clear hierarchy inside each popup.

Popup content
  1. Delete the template’s sample popup content.
  2. Add a bold line for the number of species seen.
  3. Add the descriptive information in a paragraph below it.
  4. Check the spreadsheet for the exact field names and capitalization.
<b>{{ species_seen }} species seen</b>
<p>{{ info }}</p>
Popups can include richer media: HTML can also display linked images, video, or other embedded content when the necessary URLs and accessible descriptions are stored in the data.
Do not overload the popup: Include details that help readers evaluate or understand the location. Avoid turning every popup into a miniature article.

Section 9: Control the starting view and interaction

Set a deliberate initial view, then prevent readers from panning or zooming far beyond the project’s geographic scope.

Set the initial center and zoom

Use a fixed centroid instead of allowing Flourish to frame every point automatically.

Initial viewport
  1. Open Viewport and interaction.
  2. Change the initial viewport from Auto to Centroid.
  3. Set latitude to 41.75.
  4. Set longitude to -91.6.
  5. Set the initial zoom to 10.
The starting view is editorial: It should reveal enough destinations to explain the project while still suggesting that readers can explore nearby areas.

Limit panning and zooming

Constrain the interaction so readers cannot wander into unrelated states or zoom to an unusable scale.

Interaction bounds
  1. Set the minimum zoom to 10.
  2. Set the maximum zoom to 14.
  3. Turn on Limit viewport bounds.
  4. Set the minimum longitude to -92.
  5. Set the maximum longitude to -91.2.
  6. Set the minimum latitude to 41.4.
  7. Set the maximum latitude to 41.9.
  8. Test the map by panning in every direction and zooming in and out.
Constraints improve agency: Readers can still explore, but the map prevents interactions that lead to empty, irrelevant, or disorienting views.

Disable unnecessary controls

Keep only the interaction options that support the locator-map purpose.

Interface
  1. Turn off Allow rotation.
  2. Decide whether a full-screen control would improve the project.
  3. Leave the geolocator control off unless the map has a clear reason to use the reader’s location.
More controls do not automatically create a better map: Every visible option should help readers perform the intended task.

Section 10: Accessibility and all devices

Test the popup content, controls, labels, and constrained viewport across different input methods and screen sizes.

Complete the production checks

A slippy map must remain understandable even when hover, fine pointer control, or a wide screen is unavailable.

5 A’s

A. Accessibility

  • Use a clear title and concise instructions.
  • Make popup headings descriptive and unique.
  • Write meaningful accessible descriptions for any images or media added to popups.
  • Make sure essential information is available by click or tap rather than hover alone.
  • Confirm that source information is visible and understandable.

B. All devices

  • Test panning, zooming, and popup opening on a touch screen.
  • Check whether markers overlap excessively on narrow screens.
  • Confirm that the inset map and title do not consume too much vertical space.
  • Test the published Tilda page rather than relying only on the Flourish editor.

Section 11: Publish and embed in Tilda

Publish the visualization, copy the Flourish embed code, and place it inside a restrained container.

Publish from Flourish

The published embed loads the hosted visualization into your course page.

Publish
  1. Choose Export & publish.
  2. Select Publish to share and embed.
  3. Publish the visualization.
  4. Copy the website embed code.

Place the map in Tilda

Use a centered wrapper so the map remains readable without stretching across the entire browser window.

Embed
  1. Open the assigned Module 4 tutorial page in Tilda.
  2. Add a Custom HTML block.
  3. Wrap the Flourish embed in a container with a maximum width of 900 pixels.
  4. Center the container with automatic horizontal margins.
  5. Paste the complete Flourish embed inside the wrapper.
  6. Save, close, and publish the Tilda page.
  7. Open the public page and test the map.
<div style="max-width:900px;margin:0 auto;">
  <!-- Paste the complete Flourish embed here. -->
</div>
Test the real embed: Confirm that the starting view, pan limits, zoom limits, markers, inset map, and custom popups behave correctly after publication.

Submission

Submit the published page after checking the complete interactive map.

Upload the public URL to your published Tilda page. Do not submit the Flourish editor URL or the Tilda editor URL.
