Tutorial M4 - Custom Map

Build a Custom Locator Map with D3

In this tutorial, you will build a custom map of Iowa from multiple GeoJSON files. You will use an Iowa boundary for geographic context, add polygons showing Iowa landform regions, and draw a separate layer that points out selected geological features.

D3 will convert the geographic coordinates into SVG paths. The landform polygons will display tooltip information, and readers will be able to turn the custom feature layer on and off.

A custom map uses only the geographic context the story needs. Instead of starting with a full basemap, you will choose the boundaries, labels, layers, and interactions that help readers understand this specific place.

What you will build

A responsive SVG locator map with an Iowa background, landform-region polygons, hover and focus tooltips, and a toggleable custom polygon layer.

What you will submit

The public GitHub Pages URL for the completed map and the complete project folder containing the HTML, CSS, JavaScript, and GeoJSON files.

Section 1: Understand the map layers

The final map uses three separate datasets with three different jobs.

Separate context, information, and annotation

Concept
  • Iowa boundary: An administrative boundary that establishes the map extent and provides geographic context.
  • Landform lobes: The main thematic layer. These polygons divide Iowa into geological regions and carry tooltip attributes.
  • Custom features: Hand-drawn polygons that call attention to a few especially interesting geological areas.
GeoJSON does not formally create visual layers

The datasets become layers when your JavaScript places each group of SVG paths inside a separate <g> element. That structure lets you style, reorder, hide, or show each group independently.

Section 3: Prepare the landform-lobe Shapefile

Import and simplify the polygons in Mapshaper

Step 3
  1. Open Mapshaper and add all parts of the landform-region Shapefile together.
  2. Confirm that the polygons appear and that the attribute table is attached.
  3. Click Simplify.
  4. Use the default weighted-area method unless the geometry develops obvious problems.
  5. Reduce the detail enough to make the file smaller while preserving recognizable boundaries.
  6. Turn on Prevent shape removal if small polygons begin disappearing.
  7. Apply the simplification and inspect the result at several zoom levels.
Simplification removes unnecessary vertices

The goal is not to make the shapes crude. It is to remove coordinate detail that will not be visible at the map’s final display size.

Section 4: Add tooltip information in Mapshaper

Create a field named tooltip

Step 4

You can complete this step in Mapshaper. You do not need to move the landform data into geojson.io.

  1. Turn on Mapshaper’s data-inspection tool and select a polygon.
  2. Review the existing attributes to see whether a useful region-name field already exists.
  3. Add a field named tooltip.
  4. Enter the sentence or short description that should appear for that polygon.
  5. Repeat for each landform region.
  6. Export the layer as GeoJSON and name it landform-lobes.geojson.
  7. Move the exported file into the project’s data folder.

Console option

The Mapshaper console can also create a field with -each. This is useful when a value can be copied or calculated consistently.

-each 'tooltip = NAME'

Replace NAME with the existing attribute that contains the landform name. For individually written descriptions, editing the records through the inspection interface is more direct.

Section 5: Draw custom geological features

Create a separate annotation layer in geojson.io

Step 5
  1. Open geojson.io.
  2. Load the supplied iowa.geojson file so you can draw in the correct location.
  3. Use the polygon tool to outline the first geological feature.
  4. Add a name property and a short description property.
  5. Draw the remaining feature polygons and add the same properties to each one.
  6. Delete the Iowa background feature before exporting so this file contains only your custom polygons.
  7. Save the result as custom-features.geojson inside the project’s data folder.
These polygons are explanatory, not authoritative

Draw only as precisely as the story requires. The map should identify and discuss the feature without implying a surveyed or legally exact boundary.

Section 7: Create a responsive SVG

Use a viewBox instead of fixed display dimensions

Step 7
const width = 900;
const height = 650;

const svg = d3.select("#map")
  .append("svg")
  .attr("viewBox", [0, 0, width, height])
  .attr("role", "img")
  .attr("aria-labelledby", "mapTitle mapDescription");

svg.append("title")
  .attr("id", "mapTitle")
  .text("Iowa landform regions");

svg.append("desc")
  .attr("id", "mapDescription")
  .text("A map showing Iowa landform regions and selected geological features.");

const iowaLayer = svg.append("g").attr("class", "iowa-layer");
const landformLayer = svg.append("g").attr("class", "landform-layer");
const featureLayer = svg.append("g").attr("class", "feature-layer");

The order matters. SVG draws later elements on top of earlier elements, so the Iowa context goes first and the custom feature layer goes last.

Section 9: Project and draw the map layers

Use one Albers USA projection for every layer

Step 9
function drawMap(iowa, landforms, customFeatures) {
  const projection = d3.geoAlbersUsa()
    .fitExtent([[30, 30], [width - 30, height - 30]], iowa);

  const path = d3.geoPath(projection);

  iowaLayer.selectAll("path")
    .data(iowa.features)
    .join("path")
    .attr("d", path);

  landformLayer.selectAll("path")
    .data(landforms.features)
    .join("path")
    .attr("d", path)
    .attr("tabindex", 0);

  featureLayer.selectAll("path")
    .data(customFeatures.features)
    .join("path")
    .attr("d", path);
}
Fit the projection to the Iowa boundary

fitExtent() calculates the scale and translation needed to place Iowa inside the SVG with consistent margins. Reuse that projection for the landforms and custom polygons so the layers align.

Section 10: Add accessible tooltips

Show the same information on hover and keyboard focus

Step 10
const tooltip = d3.select("#tooltip");

function showTooltip(event, feature) {
  tooltip
    .text(feature.properties.tooltip || "No description available")
    .classed("is-visible", true)
    .style("left", `${event.pageX + 12}px`)
    .style("top", `${event.pageY + 12}px`);
}

function hideTooltip() {
  tooltip.classed("is-visible", false);
}

landformLayer.selectAll("path")
  .on("pointerenter pointermove", showTooltip)
  .on("pointerleave", hideTooltip)
  .on("focus", function(event, feature) {
    tooltip
      .text(feature.properties.tooltip || "No description available")
      .classed("is-visible", true)
      .style("left", "1rem")
      .style("top", "1rem");
  })
  .on("blur", hideTooltip);

Each landform path receives tabindex="0" in the previous step. That makes the polygons keyboard-focusable rather than limiting the information to mouse users.

Section 11: Toggle the custom feature layer

Connect the checkbox to the SVG group

Step 11
d3.select("#featureToggle").on("change", function() {
  featureLayer
    .classed("is-hidden", !this.checked)
    .attr("aria-hidden", String(!this.checked));
});
.feature-layer {
  opacity: 1;
  transition: opacity 200ms ease;
}

.feature-layer.is-hidden {
  opacity: 0;
  pointer-events: none;
}
Hide the group, not each polygon separately

Because the custom polygons are collected in one SVG group, a single class can control the complete layer.

Section 13: Test the final project

Check data, interaction, and production quality

Step 13
  • Confirm that the Iowa boundary, landform polygons, and custom polygons align.
  • Check the browser console for missing files or GeoJSON errors.
  • Hover over every landform region and review its tooltip text.
  • Use the Tab key to reach every landform polygon and confirm the tooltip also appears on focus.
  • Turn the custom feature layer off and on several times.
  • Test the map from wide desktop screens down to narrow phone widths.
  • Check that the map has no horizontal scrolling and that the tooltip remains readable.
  • Confirm that the map title, introductory text, legend or explanatory key, and source attribution are present.
