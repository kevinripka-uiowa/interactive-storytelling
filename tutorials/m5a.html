Tutorial M5A

Build a Draw-the-Line Visualization

Create a Flourish visualization that asks viewers to predict a trend before revealing the actual data.

The example uses fictional bird-population data. Viewers draw what they think happened, submit their guess, and then compare it with the recorded line.

This is participatory because the viewer contributes before receiving the answer. The interaction creates curiosity, and the reveal provides immediate feedback.

What you will build

A draw-the-line chart about cumulative bird-population loss since 1900.

Video walkthrough

Section 1: Explore participatory templates

Begin by seeing how Flourish structures interactive templates before choosing the one you will build.

Look at the available interaction patterns

Step 1
  1. Log in to Flourish.
  2. Select New visualization.
  3. Open the quiz template briefly and examine its preview and data sheets.
  4. Notice that a quiz may use separate sheets for questions, answers, feedback, and final results.
  5. Return to the template gallery rather than building the quiz.
Inspect unfamiliar templates before committing

Flourish templates may expect particular column names, input types, or multiple sheets. Preview the example and consult the template documentation when the data structure is not obvious.

Section 2: Start a draw-the-line chart

Choose a template that asks the viewer to predict a line-chart trend.

Create the simple draw-the-line version

Step 2
  1. Select New visualization.
  2. Find the Draw the line templates.
  3. Choose the simple version.
  4. Test the example by drawing a guess and selecting the completion button.
  5. Notice how Flourish reveals the actual line and displays the gap between the prediction and the data.
Use this pattern for an ordered trend

Draw-the-line charts work best when the horizontal axis has a meaningful sequence, usually time. The viewer predicts how the measure changes across that sequence.

Section 3: Upload the data

Replace the sample values with the supplied bird-population dataset.

Import the tutorial CSV

Step 3
  1. Open the template's Data tab.
  2. Select the option to upload or import data.
  3. Choose fake-bird-population-loss-1900-2025.csv from the M5A tutorial assets.
  4. Confirm the import and replace the sample data.
  5. Inspect the available columns, including the population index and cumulative percent lost since 1900.
The tutorial data are fictional

The dataset is designed to practice the interaction pattern. It does not represent measured bird-population counts and should not be presented as real reporting.

An index is not a raw count

A population index expresses change relative to a starting value. The percent-loss column translates that indexed change into a measure that is easier to use for this question.

Section 4: Assign the data columns

Tell Flourish which column controls time and which line the viewer will predict.

Connect the year and percent-loss columns

Step 4
  1. Use the year column for the horizontal or time axis.
  2. Assign the cumulative percent-loss column as the line the user will guess.
  3. Leave the Always visible lines field empty for this exercise.
  4. Return to the preview and confirm that the chart now uses the bird data.
The guessed line should answer the prompt

The question asks viewers to estimate cumulative population loss, so the guessed series should use the percent-loss column rather than the population index.

Section 5: Set the visible starting amount

Decide how much of the actual line viewers see before they begin drawing.

Reveal only enough data to establish the starting point

Step 5
  1. Find the setting controlling how much of the line is initially visible.
  2. Try values such as 25 percent and 5 percent.
  3. Choose a small starting amount that establishes the trend's origin without giving away the outcome.
  4. Test the chart again from the beginning.
Do not reveal too much

The visible segment should orient the viewer and provide a place to begin drawing. If it exposes too much of the trend, the prediction becomes less meaningful.

Section 6: Customize the drawing

Adjust how the viewer's predicted line appears and behaves.

Test the line controls

Step 6
  1. Find the controls for line width, point radius, and drawing-dash size.
  2. Compare straight, stepped, and curved drawing styles.
  3. Use the preview to test how each option feels while drawing.
  4. Keep the straight line for the tutorial unless another option communicates your data more clearly.
  5. Change the drawing color to the course green or another purposeful color from your project.
Appearance affects usability

The viewer must be able to see the line while drawing it. Use sufficient contrast, an appropriate stroke width, and points that do not obscure the chart.

Section 7: Revise prompts and feedback

Use concise language to tell viewers what to draw and what happens after they submit.

Write the interaction messages

Step 7
  1. Open the template's message settings.
  2. Replace the default drawing prompt with a concise instruction such as Draw a line: Guess what percent of the bird population has been lost.
  3. Keep the prompt short enough to fit comfortably in the visualization.
  4. Rename the completion button from I'm done to Check my guess.
  5. Review the result thresholds for great, good, okay, and poor guesses.
  6. Customize the feedback text when the default messages do not fit your topic.
Prompt the exact action

Tell viewers what to draw and what the line represents. Avoid forcing the title, subtitle, and drawing prompt to repeat the same long question.

Feedback can use error thresholds

The template compares the viewer's line with the actual data. Its result categories can be adjusted according to how much difference counts as a strong or weak prediction.

Section 8: Add framing and accessibility

Give the visualization enough context to stand on its own and provide an accessible description.

Add the header and accessibility text

Step 8
  1. Open the Header settings.
  2. Add the title Bird population loss since 1900.
  3. Add a short subtitle or introductory sentence when the title alone does not explain the task.
  4. Check that the drawing prompt is not too long for the available space.
  5. Open the accessibility settings.
  6. Write a useful description explaining that the chart asks viewers to estimate cumulative bird-population loss before revealing the fictional trend.
  7. Review the axis, legend, number formatting, date formatting, and layout settings as needed.
Do not rely on the interaction alone

The header should frame the subject, and the accessibility description should explain the chart's purpose and content for viewers who cannot use the drawing interaction visually.

Section 9: Publish and copy the embed

Publish the Flourish project and retrieve the code needed for Tilda.

Publish the visualization

Step 9
  1. Rename the Flourish project to something recognizable, such as Bird population loss.
  2. Select Export & publish.
  3. Open Publish, share, and embed.
  4. Publish the visualization.
  5. Copy the responsive embed code.
Copy the embed, not the editor address

The editor URL is not the public visualization. Use Flourish's published embed code so the interactive can load inside another page.

Section 10: Embed it in Tilda

Place the published Flourish visualization into the module page and constrain its width.

Add the embed to a Tilda HTML block

Step 10
  1. Log in to Tilda and open your course project page.
  2. Add a T123 HTML Code block where the visualization should appear.
  3. Paste the Flourish embed code.
  4. Wrap the embed in a div with a maximum width and automatic left and right margins.
  5. Place the closing div after the complete embed code.
  6. Save, publish, and open the live page.
  7. Test drawing and submitting a prediction on the published page.

The wrapper controls the presentation

The Flourish embed remains responsive, while the wrapping div prevents it from becoming unnecessarily wide on a large screen.
