Tutorial M5B

Build a Coded Goofy Comparison

Build a small participatory interactive that asks viewers for their height and compares it with the 9.5-foot wingspan of a California condor.

You will assemble the project gradually so you can see how the form, blank state, error checking, calculation, visual feedback, and written feedback work together.

You would likely vibe code an interactive like this with AI. The goal here is not to memorize every line. Building it slowly helps you recognize the parts, test the output, and revise AI-generated code rather than treating it as a black box.

What you will build

A height form that draws a centered comparison line beneath a trimmed raster image of a California condor and explains the result.

Section 4: Add the form

Add the controls that collect the viewer's height.

Add a real form above the SVG stage

Step 4

Paste this inside <div class="condor-compare__panel">, immediately before the stage.

               inputmode="numeric">
      </label>

      <button type="submit">Compare</button>

Why use a form element?

The form identifies these controls as one input task. A submit button works with a mouse, keyboard, and mobile keyboard without requiring separate Enter-key code. JavaScript will later intercept submission with preventDefault() so the page does not reload.

Fieldset and legend describe the group

The fieldset groups the feet and inches controls, while the legend gives that group an accessible name. Each label is explicitly connected to its input with for and id.

Section 5: Add the result and blank state

Add the region that will first provide instructions and later display validation messages and the personalized comparison.

Add a live result region below the form

Step 5

Paste this after the closing </form> tag and before the SVG stage.

<div class="condor-compare__result"
     id="condorResult"
     aria-live="polite">
  Enter your height to begin the comparison.
</div>
The page begins in a blank state

The inputs contain no default values, no personalized line is visible, and the result region gives a neutral instruction. A blank state is not an empty page; it explains what the viewer should do next.

One region can show several states

JavaScript will later replace the initial instruction with an error message or a completed comparison. aria-live="polite" tells screen readers to announce those updates at a natural pause.

JavaScript will manipulate attributes

The line begins without horizontal coordinates. Later, JavaScript will calculate and set its x1 and x2 values. It will set matching coordinates for the end caps and keep the label at the condor's center.

Keep unavailable output hidden

The entire SVG group begins with the hidden attribute because the page does not yet have a height to represent. Since the group is an SVG element, JavaScript will explicitly add or remove that attribute rather than relying on the HTML-only .hidden property.

Section 7: Connect JavaScript to the page

JavaScript must first identify the controls and output elements it will use.

Create constants for the interface

Step 7

Paste this inside the script element.

(() => {
  const CONDOR_INCHES = 9.5 * 12;

  const form = document.getElementById('condorForm');
  const feetInput = document.getElementById('condorFeet');
  const inchesInput = document.getElementById('condorInches');
  const result = document.getElementById('condorResult');

  const barGroup = document.getElementById('condorBarGroup');
  const personBar = document.getElementById('condorPersonBar');
  const barStart = document.getElementById('condorBarStart');
  const barEnd = document.getElementById('condorBarEnd');
  const personLabel = document.getElementById('condorPersonLabel');

Namespace the JavaScript too

The IDs all begin with condor, and the code is wrapped in an immediately invoked function. This keeps its variables out of the global scope when the snippet is pasted into a larger Tilda page.

Section 8: Create the blank state

Make one function responsible for returning the interface to its neutral starting condition.

Add a reusable blank-state function

Step 8

Add this below the constants, but still inside the wrapper function.

function showBlankState(message = 'Enter your height to begin the comparison.') {
  barGroup.setAttribute('hidden', '');
  result.textContent = message;
}
A blank state is designed, not empty

It tells viewers what to do before data exists. The same function can also hide an old result when new input is incomplete or invalid. setAttribute() is used because the hidden element is an SVG <g>, not a regular HTML element.

Section 9: Check the input

Validate the form before using the viewer's values in a calculation.

Start the comparison function

Step 9
function updateComparison() {
  const feetText = feetInput.value.trim();
  const inchesText = inchesInput.value.trim();

  if (feetText === '' || inchesText === '') {
    showBlankState('Enter both feet and inches.');
    return;
  }

  let feet = Number(feetText);
  let inches = Number(inchesText);

  if (!Number.isFinite(feet) || !Number.isFinite(inches)) {
    showBlankState('Enter numbers for both fields.');
    return;
  }

  if (feet < 2 || feet > 9 || inches < 0 || inches > 11) {
    showBlankState('Enter 2–9 feet and 0–11 inches.');
    return;
  }
}
HTML limits are not enough

The feet field can allow values through 9 and the inches field through 11, but HTML cannot express a combined maximum of 9 feet 6 inches. JavaScript must check the total height before drawing the comparison.

Why use return?

After an error is found, return stops the function. Without it, the code could continue and draw a comparison using incomplete or invalid values.

Section 10: Process the values

Convert the viewer's height into the same unit used for the condor wingspan.

Calculate the ratio

Step 10

Add this at the end of updateComparison(), before its closing brace.

feet = Math.round(feet);
inches = Math.round(inches);

const totalInches = feet * 12 + inches;

if (totalInches > CONDOR_INCHES) {
  showBlankState('Enter a height no taller than 9 ft 6 in.');
  return;
}

const ratio = totalInches / CONDOR_INCHES;
const percent = Math.round(ratio * 100);
Compare like units

The condor wingspan is converted from feet to inches once. The viewer's feet and inches are also combined into inches. That total makes it possible to reject anything above 114 inches—or 9 feet 6 inches—and then calculate a valid ratio using the same unit.

Test the upper limit

Enter 9 feet and 6 inches. The result should be exactly 100%, and the comparison line should span the full width of the condor image.

Section 11: Draw the centered line

Use the ratio to determine the line's width and position it evenly around the condor's center.

Set the SVG line measurements

Step 11

Add this next inside updateComparison().

const condorWidth = 1002;
const centerX = 501;
const lineWidth = Math.min(condorWidth * ratio, condorWidth * 1.15);
const barX = centerX - lineWidth / 2;
const barEndX = centerX + lineWidth / 2;

barGroup.removeAttribute('hidden');

personBar.setAttribute('x1', barX);
personBar.setAttribute('x2', barEndX);

barStart.setAttribute('x1', barX);
barStart.setAttribute('x2', barX);

barEnd.setAttribute('x1', barEndX);
barEnd.setAttribute('x2', barEndX);

personLabel.setAttribute('x', centerX);
personLabel.textContent = `Your height: ${feet} ft ${inches} in`;

Section 12: Return feedback

Explain the result in words instead of relying only on the visual bar.

Write the personalized comparison

Step 12

Add this after the line code inside updateComparison().

const peopleAcross = CONDOR_INCHES / totalInches;

result.innerHTML = `
  At <strong>${feet} ft ${inches} in</strong>,
  your height is about <strong>${percent}%</strong>
  of a California condor's wingspan.
  About <strong>${peopleAcross.toFixed(1)} people</strong>
  your height could fit head-to-toe across the wings.
`;
Feedback should teach

The result connects directly to the viewer's input, interprets the ratio, and provides a second familiar comparison.

Section 13: Trigger the calculation

Use the form submission event to handle both the button and the Enter key.

Listen for form submission

Step 13

Add this after the updateComparison() function.

form.addEventListener('submit', event => {
  event.preventDefault();
  updateComparison();
});

showBlankState();
Events connect input to behavior

The form fires the same submit event whether the viewer clicks the button or presses Enter inside an input. preventDefault() stops the browser from reloading the page. The final line explicitly establishes the blank state when the page loads.
