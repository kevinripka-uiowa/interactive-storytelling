Build a Native Accordion Block in Tilda

In this tutorial, you will use Tilda to build an accordion as a native block. The goal is not only to learn where the accordion block lives, but also to practice deciding whether a native block gives you enough control for your story content.

Native blocks are useful until they are not. A native block is usually the best first option when it fits the purpose and pattern. It is fast, responsive, and often more accessible than a custom build. But the block also defines your limits.

What you will build

An accordion explaining bird identification clues, with a heading, four accordion items, images, alt text, and attribution.

Video walkthrough

Replace the placeholder YouTube URL with the tutorial video URL when the video is ready.

Before you start

Gather the required materials before opening the builder.

Preparation

Have the tutorial content and assets ready so the build work stays focused on the Tilda workflow.

Setup
  • Download the native block assets from ICON.
  • Open the text file from the asset folder so you can copy and paste the accordion content.
  • Have the images and audio files available in the same folder.

Section 1: Set up the page

Start from your assigned page and add a simple section heading before the accordion.

Set up the tutorial area

This creates a basic section label before you add the interactive block.

Page setup
  1. Log in to tilda.cc.
  2. Open your assigned tutorial page in Tilda.
  3. Click to add a new block.
  4. Choose a simple text block, such as Title and Text.
  5. Use the title to mark the section as Module 2.
  6. Remove any placeholder text you do not need.

Section 2: Find the native accordion block

Tilda may not use the word accordion, so look for the behavior rather than only the name.

Find and test the block

The accordion block may appear as a drop-down, toggle, expander, collapsible text, or FAQ-style block.

Native block
  1. Click to add a new block.
  2. Look through the block library. Tilda may not use the word accordion.
  3. Go to the text block options.
  4. Find the block called Text in drop-down items on the background, or the similar drop-down text block without a background.
  5. Choose the version whose default styling fits your page better.
  6. Click the block to add it to the page.
  7. Test the default items by opening and closing them. Confirm that the basic interaction is what you expected.
Note: Builder labels are not always the labels you would use in class. Browse related block categories and test the block behavior.

Section 3: Add the accordion content

Use the asset text file to fill the accordion items cleanly and consistently.

Add item titles and descriptions

Most of the content work belongs in Tilda’s Content panel.

Content
  1. Open the asset text file.
  2. Copy the title for the first accordion item, such as Size and Shape.
  3. Paste it into the first item title field.
  4. Copy the body text for that item and paste it into the description field.
  5. Use the formatting toolbar to clean up the text. For example, convert clue lists into a marked or bulleted list.
  6. Repeat this process for the remaining existing accordion items.
  7. If you need more accordion items, open Content, choose Items, and click Add a new item.
  8. Add the fourth item in the Content panel rather than trying to force it into the visible page editor.
  9. Save and close when the four content categories are in place.
Using Tilda: Content usually controls what the block says or contains. Settings usually control layout, behavior, and visual styling.

Section 4: Test the block’s capabilities

A native block should be tested before you commit to it.

Test what the block can and cannot do

In this example, the accordion can hold text and one image per item, but it does not support audio inside the accordion item.

Control limits
  1. Open Content, then Items.
  2. Open the first accordion item.
  3. Use the upload field to add the image for that item.
  4. Repeat for the other items that need images.
  5. Look for a way to add a second image or an audio file.
  6. Try uploading an audio file only as a test. Tilda should reject the unsupported file type.
  7. Use that result to decide whether the native block is still appropriate for the full content plan.
Control versus responsibility: Native blocks usually give you low control and low responsibility. Tilda handles much of the technical work, but you may not be able to place images exactly where you want, add multiple media items, or include unsupported media types such as audio.

Section 5: Appearance

Appearance includes the block’s structural design, expressive design, and attendant text. For this tutorial, prioritize clean structure over elaborate styling.

Set the appearance and behavior

Use Content for the words and Settings for layout, styling, and behavior.

Design

A. Add attendant text

  1. Open the accordion block Content panel.
  2. Add the block title: Bird Identification Clues.
  3. Add the short introduction that explains what the reader will learn or do.
  4. Save and close to view the block header above the accordion.

B. Adjust basic layout and styling

  1. Open Settings for the accordion block.
  2. Look for Block width and decide whether the accordion should be centered or wider on the page.
  3. Look for Block header settings if the title and description need different alignment or spacing.
  4. Adjust title and description font sizes if the hierarchy feels wrong.
  5. Use margin and padding controls to reduce awkward gaps, but do not spend too long chasing minor spacing issues during a tutorial build.
  6. Look under Item styles if you want to change item background, typography, or image width.
Clean is enough here: The goal is to make the accordion readable, organized, and appropriate for the content.

C. Set accordion behavior

  1. In Settings, look for accordion behavior options.
  2. Consider turning on Collapse all items except for the selected one if you want only one section open at a time.
  3. Consider turning on scrolling to the expanded item if long items cause the reader to lose their place.
  4. Preview the behavior by opening items in different orders.
Note: The one-open-at-a-time behavior can reduce clutter, but it can also feel jumpy if one item is much longer than another.

D. Handle image sizing carefully

  1. If an image appears too large, first look for an image-width setting in the block Settings panel.
  2. Avoid using Tilda’s image editor to permanently resize an image just to make it display smaller on the page.
  3. If a setting changes all item images at once, decide whether that global control is acceptable.
  4. If each image needs a different size or placement, the native block may not give you enough control.
Do not confuse file size with display size: Display size is a layout setting. File size is an asset optimization issue.

Section 6: Asset optimization

Asset optimization means making sure the media files are appropriate for the web.

Check media files

In a native Tilda block, the platform handles much of the image processing automatically, but you should still understand what is happening.

Performance
  • Images: Tilda will usually optimize uploaded images for delivery, so you do not need to manually create multiple responsive image sizes for this tutorial.
  • Audio: this block does not accept the audio files, so you cannot evaluate audio optimization inside this native accordion.
  • File choice: even when a builder optimizes files, start with reasonable web assets. Do not upload huge files just because the builder will compress them.
  • Image clarity: if you use the image editor to downsize the original file, you may create a blurry result. Use layout controls for display size whenever possible.

Section 7: All Devices

All Devices means checking that the accordion works on desktop and mobile.

Test responsiveness

Native blocks usually do well here because the builder has already made responsive decisions.

Responsiveness
  1. Click Preview.
  2. Review the desktop version first.
  3. Switch to the mobile preview.
  4. Open and close each accordion item on mobile.
  5. Check whether text, images, spacing, and scrolling still feel usable.
  6. Return to the editor if the mobile view needs adjustment.

When desktop and mobile need different designs

  1. Switch to the mobile view in the editor.
  2. Look for the small desktop or device icon next to typography or spacing controls.
  3. Use device-specific settings when a font size, margin, or layout needs to change only on mobile.
  4. If a block cannot work well across devices, duplicate the section and create a mobile-specific version.
  5. Hide the desktop version on mobile and hide the mobile version on desktop.
  6. Use this two-version approach only when necessary. It increases maintenance work.

Section 8: Accessibility

Accessibility is partly handled by the native block, but you still need to check the things you control.

Check access and readability

Focus on readable text, alt text, keyboard access, and clear instructions.

Accessibility

A. Add alt text to images

  1. Open the accordion block Content panel.
  2. Go to Items.
  3. Open an item that contains an image.
  4. Click the three-dot menu for the image.
  5. Find the Alt text field.
  6. Write a short description of the image’s information or purpose.
  7. Repeat for each image.
  • Example: Bird silhouettes pointing out the shapes of various bird families.
  • Example: Bird topography chart showing labeled body areas.
  • Example: Diagram of multiple bill shapes.
Alt text should serve the content: Do not write alt text as a file label. Write what the image contributes to the reader’s understanding.

B. Check keyboard access

  1. Publish the page so you can test the real page rather than only the editor preview.
  2. Open the published page in a browser.
  3. Use the Tab key to move through the accordion items.
  4. Use Enter or Return to open an item.
  5. Confirm that the accordion can be operated without a mouse.

C. Check readable design and HTML support

  • Keep text readable against the background.
  • Do not use color as the only way to communicate meaning.
  • Avoid unnecessary animation. This block has minimal motion, so reduced-motion concerns are limited.
  • Use clear headings and introductory text so the reader knows what the accordion is for.
  • Native blocks may already include ARIA attributes such as aria-controls. You do not need to write ARIA yourself for this tutorial, but it is useful to know the builder is doing some of that work.

Section 9: Attribution

Attribution means explaining where the information and media came from.

Add source and image credits

If the accordion summarizes outside sources or uses outside images, credit those sources clearly.

Attribution

A. Add source attribution below the accordion

  1. Add a new simple text block below the accordion.
  2. Paste a concise attribution sentence for the information source.
  3. Use Settings to reduce the font size so the attribution reads like a note, not a new main section.
  4. Set top padding on the attribution block to zero or a small value.
  5. Return to the accordion block Settings and reduce bottom padding if the gap between the accordion and attribution is too large.
  6. Publish again after the attribution is in place.

B. Add image attribution where needed

  1. Open the accordion item that contains the image.
  2. Add a short photo credit inside the item description after the main body text.
  3. Style the credit smaller or lighter only if it remains readable.
  4. Repeat for each image that requires attribution.
  5. If the block does not provide a dedicated caption or credit field, place the credit in the text area.
Do not fake semantics unless you have to: Superscript can make a credit look smaller, but it is not technically the right semantic choice unless the text is actually superscript. Use real font-size controls when the builder allows it.

Section 10: Publish and confirm the final page

Preview is useful while building, but final checks should happen on the published page.

Final confirmation

Tilda changes are not live until you publish.

Publish
  1. Click Publish in Tilda.
  2. Open the published page link.
  3. Refresh the page if needed to confirm the latest changes are live.
  4. Open each accordion item and check the final content.
  5. Check the mobile preview or resize the browser window.
  6. Use the keyboard to confirm basic accessibility.
  7. Confirm that attribution appears below the accordion and inside image items as needed.
Preview is not the same as published: Use preview while building, but use the published page for final checks and for anything you plan to submit.
