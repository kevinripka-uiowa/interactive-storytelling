Build a Custom Iowa Map with D3

You will prepare Iowa landform data in Mapshaper, draw your own point, line, and polygon features in geojson.io, and combine the three datasets in a responsive SVG map.

The workflow has two parts: prepare clean geographic data first, then write the code that projects, draws, styles, and adds interaction to it.

What you will build

An Iowa landform map with individually colored lobes, custom point, line, and polygon annotations, tooltips, and a checkbox that shows or hides the custom layer.

What you will submit

A zipped project folder containing your HTML, CSS, JavaScript, and three GeoJSON files.

Video walkthrough

Follow the complete process in the recorded tutorial, then use the written steps below as a reference while you work.

Section 1: Set up the project folder

Create the complete working structure before downloading or editing data.

Create the files in Visual Studio Code

Setup
  1. Create a folder named iowa-custom-map.
  2. Open that folder in Visual Studio Code.
  3. Create index.html, styles.css, and script.js.
  4. Create a folder named data.

Section 2: Download the Iowa landform Shapefile

Download the source data

Data
  1. Open the Iowa landform regions dataset page.
  2. Download the Shapefile version.
  3. Unzip the download.
  4. Keep all Shapefile parts together.
A Shapefile is a bundle

The geometry, attributes, and coordinate-system information are split across files such as .shp, .dbf, .shx, and .prj. Mapshaper needs the related files together.

Section 3: Import the Shapefile into Mapshaper

Upload all related files at once

Mapshaper
  1. Open mapshaper.org.
  2. Drag the complete set of Shapefile parts into the import window, or select all of them together with the file picker.
  3. Do not upload only the .shp file. The .dbf contains the attribute table, and the .prj identifies the source projection.
  4. Choose Import and confirm that the polygons appear.
  5. Open the data table and verify that the landform-name field is present.

Section 4: Reproject the data to WGS84

Convert projected coordinates to longitude and latitude

Projection

The source data uses a projected coordinate system measured in linear units. D3 geographic projections work most predictably when GeoJSON uses WGS84 longitude and latitude.

  1. Open Mapshaper’s Console.
  2. Run:
-proj wgs84
  1. Export the layer as GeoJSON before simplifying it.
  2. Record the downloaded file size. This gives you a baseline for comparison.
How to recognize WGS84

Iowa coordinates should look approximately like longitude -97 to -90 and latitude 40 to 44. Six- or seven-digit coordinate values usually indicate a projected system rather than longitude and latitude.

Section 5: Simplify the lobes and add tooltip data

Reduce the file to 10 percent of its detail

Optimize
  1. Choose Simplify.
  2. Keep the default weighted-area method.
  3. Set the retained detail to 10%.
  4. Turn on Prevent shape removal if small polygons disappear.
  5. Apply the simplification and inspect the boundaries.
  6. Open the data table.
  7. Add a field named tooltip.
  8. Enter the text that should appear for each lobe. You may copy the landform name into this field or write a fuller description.
  9. Export the simplified layer as GeoJSON.
  10. Record the new file size and compare it with the unsimplified export.

Console shortcut for the tooltip field

-each 'tooltip = LANDFORM_R'

Replace LANDFORM_R if the landform-name field uses a different name.

Section 6: Dissolve the lobes into an Iowa outline

Create one background polygon

Context layer
  1. Duplicate or re-import the simplified lobe layer so you can preserve the original lobes.
  2. Select the copy.
  3. Run this command in the console:
-dissolve
  1. The internal lobe boundaries should disappear, leaving one Iowa outline.
  2. Add a data field named name and give it the value Iowa.
  3. Export the dissolved layer as GeoJSON.
Rename Mapshaper exports

Mapshaper may download GeoJSON with a .json extension. Rename the files to lobes.geojson and iowa.geojson, then move them into the project’s data folder.

Section 7: Draw custom features in geojson.io

Create a point, line, and polygon

Custom layer
  1. Open geojson.io.
  2. Load iowa.geojson for geographic reference.
  3. Draw one point, one line, and one polygon.
  4. Select each feature and add a property named tooltip.
  5. Enter a short description for each feature.
  6. Delete the Iowa reference polygon before exporting.
  7. Export the custom features as GeoJSON.
  8. Rename the file custom-features.geojson and place it in the data folder.
data/
├── iowa.geojson
├── lobes.geojson
└── custom-features.geojson

Section 9: Create a responsive SVG

Create the canvas and layer groups

JavaScript

const width = 900;
const height = 600;

const svg = d3.select("#map")
  .append("svg")
  .attr("viewBox", [0, 0, width, height])
  .attr("role", "img")
  .attr("aria-labelledby", "mapTitle mapDescription");

svg.append("title")
  .attr("id", "mapTitle")
  .text("Iowa landform regions");

  .attr("id", "mapDescription")
  .text("A map of Iowa landform lobes with custom point, line, and polygon features.");

const iowaLayer = svg.append("g").attr("class", "iowa-layer");
const lobeLayer = svg.append("g").attr("class", "lobe-layer");
const customLayer = svg.append("g").attr("class", "custom-layer");

Wait until every dataset has loaded

Section 11: Project and draw the map layers

Use one projection for all geometry types

JavaScript
function slugify(value = "") {
  return value
    .toLowerCase()
    .trim()
    .replace(/[^a-z0-9]+/g, "-")
    .replace(/^-|-$/g, "");
}

function drawMap(iowa, lobes, customFeatures) {
  const projection = d3.geoAlbersUsa()
    .fitExtent([[30, 30], [width - 30, height - 30]], iowa);

  const path = d3.geoPath(projection).pointRadius(7);

  iowaLayer.selectAll("path")
    .data(iowa.features)
    .join("path")
    .attr("class", "iowa")
    .attr("d", path);

  lobeLayer.selectAll("path")
    .data(lobes.features)
    .join("path")
    .attr("class", d => {
      const name = d.properties.LANDFORM_R || d.properties.name || "lobe";
      return `lobe ${slugify(name)}`;
    })
    .attr("d", path)
    .attr("tabindex", 0);

  customLayer.selectAll("path")
    .data(customFeatures.features)
    .join("path")
    .attr("class", d => {
      const type = d.geometry.type;
      if (type === "Point" || type === "MultiPoint") return "custom-point";
      if (type === "LineString" || type === "MultiLineString") return "custom-line";
      return "custom-polygon";
    })
    .attr("d", path)
    .attr("tabindex", 0);
}

geoPath() can draw polygons, lines, and points. pointRadius(7) tells it how large the point symbol should be.

Section 12: Correct polygon winding

Fix polygons that D3 reads as the outside of the shape

Debugging

You may see the SVG fill with black or another solid color. The coordinates can be correct while the polygon rings travel in a direction that makes D3 interpret the polygon as nearly the entire globe.

A polygon identifies both a border and a side

The coordinate order tells geographic software which side of the border is the polygon’s interior. Different GIS tools do not always use the same winding convention.

Add this function above drawMap():

function fixWinding(geojson) {
  geojson.features.forEach(feature => {
    const type = feature.geometry?.type;

    if ((type === "Polygon" || type === "MultiPolygon") &&
        d3.geoArea(feature) > 2 * Math.PI) {

      if (type === "Polygon") {
        feature.geometry.coordinates.forEach(ring => ring.reverse());
      } else {
        feature.geometry.coordinates.forEach(polygon => {
          polygon.forEach(ring => ring.reverse());
        });
      }
    }
  });

  return geojson;
}

Then add these lines at the beginning of drawMap():

iowa = fixWinding(iowa);
lobes = fixWinding(lobes);
customFeatures = fixWinding(customFeatures);

The test uses d3.geoArea(). A small Iowa polygon should cover a tiny part of the sphere. If D3 reports more than half the globe, the code reverses that polygon’s rings.

Section 13: Customize individual lobe colors

Use the generated class names in CSS

Style

The JavaScript turns each landform name into a CSS-safe class. For example, Southern Iowa Drift Plain becomes southern-iowa-drift-plain.

Open the browser inspector or examine the landform names in the data table to find the classes you need. Keep a visible stroke between adjacent lobes.

Section 14: Add tooltip functionality

Use one tooltip for lobes and custom features

Interaction

Add this below the layer declarations:

const tooltip = d3.select("#tooltip");

function tooltipText(feature) {
  return feature.properties.tooltip ||
    feature.properties.LANDFORM_R ||
    feature.properties.name ||
    "No description available";
}

function showTooltip(event, feature) {
  tooltip
    .text(tooltipText(feature))
    .classed("is-visible", true);

  moveTooltip(event);
}

function moveTooltip(event) {
  tooltip
    .style("left", `${event.clientX + 14}px`)
    .style("top", `${event.clientY + 14}px`);
}

function showFocusedTooltip(feature) {
  tooltip
    .text(tooltipText(feature))
    .classed("is-visible", true)
    .style("left", "1rem")
    .style("top", "1rem");
}

function hideTooltip() {
  tooltip.classed("is-visible", false);
}

At the end of drawMap(), add:

function addTooltipEvents(selection) {
  selection
    .on("pointerenter", showTooltip)
    .on("pointermove", moveTooltip)
    .on("pointerleave", hideTooltip)
    .on("focus", (event, feature) => showFocusedTooltip(feature))
    .on("blur", hideTooltip);
}

addTooltipEvents(lobeLayer.selectAll("path"));
addTooltipEvents(customLayer.selectAll("path"));

Section 15: Add the custom-layer checkbox

Hide or show the complete SVG group

Interaction

Add this after drawMap():

d3.select("#featureToggle").on("change", function() {
  const isHidden = !this.checked;

  customLayer
    .classed("is-hidden", isHidden)
    .attr("aria-hidden", String(isHidden));
});

The checkbox changes one class on the group containing the point, line, and polygon. The CSS fades the group and disables pointer interaction while it is hidden.

Try the same pattern with the landform lobes

Duplicate the existing checkbox in index.html and change its ID and label so it controls the lobes. Then duplicate the checkbox JavaScript, change the selector to the new ID, and apply the hidden class to lobeLayer instead of customLayer. You will also need a matching hidden-state CSS rule for the lobe layer.
