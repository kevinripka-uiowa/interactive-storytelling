Locate: Map Patterns

Maps help viewers understand where something happens, how places relate, and why geography changes the meaning of a story. In this module, the goal is not just to put information on a map. The goal is to choose the right map form and the right interaction pattern for the location job.

Core idea: location is a story job, not a decoration. Map interactions such as layers, markers, and popups can support many map forms. A locator map helps the viewer orient. A data map shows geographic pattern. A slippy map specifically lets the viewer pan and zoom. A scrollymap guides attention through a spatial argument.

Map interactions

These interaction patterns can apply to almost any map type below. They are not a separate map form; they are reusable behaviors that help readers inspect, filter, reveal, or compare geographic information.

Markers + popups

Markers identify specific mapped locations. Popups reveal the record attached to a marker, such as a title, value, caption, image, source note, interview quote, or link. They work together because a marker answers “where?” and the popup answers “what is here?”

Point detail

Story jobs

Best: Locate and Reveal. Also useful for: Explore when readers can inspect a collection of mapped records.

Affordances

Spatial because each marker is anchored to a place; encyclopedic because each point can hold deeper information; participatory and procedural because clicking or focusing a marker changes what is shown.

Agency

Exploratory inspection. Readers choose which location to inspect, while the author controls the set of mapped locations and the fields in each popup.

River bend

Spring warbler reports cluster along wooded river corridors where insects emerge early.

Wetland overlook

A popup can hold a caption, photo, count, link, source note, or short explanation for this mapped record.

Prairie edge

Grassland bird observations can be tied to habitat condition, management history, or conservation status.

Possible interactions

Click-to-open popups, hover labels, focus states, active-marker highlighting, side-panel detail cards, photo popups, marker clustering, marker filters, or “zoom to this point” buttons. These overlap with reveal patterns, but the reveal is anchored to a mapped location.

Layers

Layers let readers turn mapped information on or off. A layer can be a category, time period, route, risk area, habitat type, source, or reference feature. On many maps, layers function like geographic filters.

Filterable map layers

Story jobs

Best: Locate and Explore. Also useful for: Compare when layer combinations show how places differ.

Affordances

Spatial because the data is positioned geographically; participatory because readers decide which layers to view; procedural because the map redraws as layer visibility changes.

Agency

Exploratory inspection. Readers can combine categories, but the author defines the available layers and the geographic frame.

Possible interactions

Layer toggles, multi-select filters, time sliders, category checkboxes, legend controls, hover-to-highlight by layer, opacity sliders, or side-by-side layer comparison. Layers can be used on locator maps, choropleths, symbol maps, dot-density maps, slippy maps, or scrollymaps.

Data Maps

Use data maps when geography is part of the evidence. The map should help readers see distribution, concentration, connection, movement, or regional difference.

Data map type gallery

These are common map types students can use when the story is based on mapped evidence. The choice depends on whether the data is about places, areas, movement, density, totals, or normalized rates.

Map type system

Story jobs

Best: Locate. Also useful for: Compare and Explain when the map shows regional patterns or change.

Affordances

Spatial because geography carries meaning; encyclopedic when many places or records are represented; procedural when tooltips, filters, and layers change the view.

Agency

Ranges from guided reading to exploratory inspection. Simple Datawrapper maps often offer hover and zoom; Flourish or custom maps can add filtering, stories, and view switching.

Point / icon-based locator map

Best when the reader needs to find exact sites, observations, events, nests, routes stops, or story locations.

Possible interactions

Marker tooltips, popups, category filters, icon legends, hover/focus highlighting, clustered markers, or click-to-open detail panels.

Line / arc / connection locator map

Best for migration paths, routes, relationships between locations, transmission paths, or movement between places.

Possible interactions

Hover to isolate one connection, click a route for a popup, animate direction, filter by species or season, or step through route segments.

Area locator map

Best for habitat boundaries, counties, preserves, watersheds, project areas, neighborhoods, or study sites.

Possible interactions

Click polygons for descriptions, toggle area layers, compare boundaries, reveal labels, or pair with a sidebar explanation.

Choropleth

Best for rates, percentages, indexes, or comparable values across administrative areas such as counties or states.

Possible interactions

Hover tooltips for exact values, legend interaction, class toggles, time sliders, category filters, or annotated outliers.

Proportional symbol / graph map

Best when exact locations matter and the value is a total count, amount, or magnitude rather than a rate.

Possible interactions

Hover to read values, click for detail, filter symbols, scale legend inspection, or switch between total and per-capita views.

Standard cartogram

Best when the value is more important than geographic shape, such as population, observations, or total counts by region.

Possible interactions

Toggle between true geography and cartogram, hover area values, animate resize, or use guided annotations to prevent misreading.

Dorling & Demers cartogram

Best when you want a cartogram-like comparison while reducing distorted shapes to simpler marks.

Possible interactions

Hover each circle, sort or filter regions, toggle labels, animate from a regular map, or connect selected circles to detail cards.

Dot density

Best for showing where many individual records or approximate occurrences are concentrated.

Possible interactions

Zoom to inspect clusters, filter dots by category, use tooltip samples, animate time, or add a density summary on hover.

Flow map

Best for migration, commuting, shipping, dispersal, or other directional movement between places.

Possible interactions

Animate flow direction, hover to isolate a stream, filter origins/destinations, step through time, or show values in tooltips.

Hex bin map

Best when raw points are too dense or uneven and the story needs a spatial pattern rather than exact locations.

Possible interactions

Hover bin counts, filter by species or date, adjust bin resolution, animate time, or highlight high-density cells.

Spatial-Temporal Maps

Use spatial-temporal maps when mapped markers, features, categories, or values change over time. The main job is to help readers compare time periods while still understanding where the change happens.

Toggling markers and features over time

A spatial-temporal map connects place with time by changing what appears on the map at each date, period, stage, or condition. It can show markers appearing or disappearing, features changing category, routes becoming active, risk zones expanding, or values changing in the same places.

Time + place

Story jobs

Best: Locate, Compare, and Explain. The viewer needs to see where features are, how they differ across time, and what the change means.

Affordances

Spatial because location carries meaning; procedural because the map changes by rule or time step; participatory when readers choose the date, stage, or playback mode.

Agency

Ranges from no agency to hybrid control. A pure animation has no viewer agency. A stepper, slider, or period toggle gives guided or exploratory agency. A useful hybrid can animate automatically but let readers pause, scrub, and use it like a non-linear stepper.

Changing valuesThe same place remains on the map, but its count, rate, color, size, or category changes across time.
Changing featuresPoints, lines, polygons, or labels appear, disappear, become active, or change style as time advances.
Comparing periodsThe reader should be able to contrast dates, stages, or conditions rather than only watch change pass by.

Animation

Use autoplay when the point is to show a quick pattern of change. This has little or no agency unless readers can pause, replay, or scrub.

Buttons, steppers, sliders

Use period buttons, next/back controls, or a time slider when readers need to compare states deliberately.

Hybrid playback

Let the map animate first, then allow readers to stop, choose a period, move backward, or jump non-linearly between steps.

Possible interactions

Period buttons, time slider, play/pause animation, date filter, stepper, temporal layer toggles, before/after comparison, cumulative reveal, changing symbol size, changing choropleth color, marker appearance/disappearance, active route segments, or small multiples by period.

Locator Maps and Custom Map Data

Use locator maps when the reader needs to understand where the story takes place. Custom map data lets students move beyond default place search by adding points, polygons, GeoJSON, shapefiles, or cleaned boundaries.

Custom points, polygons, and boundaries

This section is about the production move from “I found a place on a map” to “I made the map data the story needs.” Students can place points from a spreadsheet, draw areas, clean shapefiles in Mapshaper, export GeoJSON, and use those shapes in a builder or custom map.

Custom geography

Story jobs

Best: Locate. Also useful for: Explain when the shape of the place affects the story.

Affordances

Spatial because custom geometry defines the story area; encyclopedic when popups hold place details; participatory when readers inspect points or layers.

Agency

Exploratory inspection. The author defines the geography, then the reader can inspect the mapped places and boundaries.

Point dataUse for observation sites, interviews, offices, landmarks, nest locations, stops, or events.
Polygon dataUse for habitat areas, neighborhoods, counties, watersheds, campus zones, or study boundaries.
Data prepMapshaper is useful for simplifying, converting, clipping, and checking GeoJSON or shapefiles before the map is built.

Possible interactions

Point popups, polygon hover states, layer toggles, custom icons, filtered categories, click-to-zoom buttons, rich annotations, or linked detail cards.

Slippy Maps

Use slippy maps when the reader needs the familiar web-map ability to move through geography. The defining interaction is direct pan and zoom: drag to move, wheel or pinch to zoom, and reset when the reader needs to return to the overview.

Pan-and-zoom map

A slippy map behaves like an online map. The viewer can drag to pan, zoom in for local detail, zoom out for context, and inspect spatial relationships at multiple scales.

Pan and zoom

Story jobs

Best: Locate and Explore. Also useful for: Explain when scale matters and the reader needs to move between overview and local detail.

Affordances

Spatial because the reader navigates geography; participatory because the reader controls movement and scale; procedural because the map repositions and rescales in response to input.

Agency

Exploratory but bounded. The author chooses the extent and basemap; the reader chooses where to look and how closely to inspect it.

Drag to pan. Use the mouse wheel, trackpad, or buttons to zoom.

Possible interactions

Dragging or swiping to pan, wheel/trackpad/pinch zoom, zoom buttons, double-click zoom, reset-to-overview, zoom-to-bounds, fit-to-feature, and scale-dependent labels. Layers, markers, and popups can be added, but pan and zoom are the core slippy-map behavior.

Guided Map Interaction

Use guided map interaction when the reader should move through a designed spatial sequence. The defining feature is not scrolling. It is author-controlled map states triggered by buttons, steppers, sliders, tabs, or other explicit inputs.

Button/input-based guided map

A guided map sequence can use buttons, a stepper, a slider, tabs, or other input controls to change map state. Each control can move attention to a place, reveal a layer, highlight a route, switch a time period, or explain why geography matters.

Guided controls

Story jobs

Best: Locate and Explain. Also useful for: Compare when each step shows a different place, scale, layer, period, or condition.

Affordances

Spatial because each state changes geographic focus or map emphasis; procedural because the map changes by rule; participatory because readers choose when to advance or which state to inspect.

Agency

Guided. The author defines the sequence and available states, but the reader controls pace and may move non-linearly if the controls allow it.

Start with the route

Begin with enough geography for readers to orient before zooming into details.

Buttons

Use buttons when each state is a distinct authored stop: place, layer, route segment, or explanatory moment.

Steppers

Use next/back controls when the order matters and readers should move through the map like a sequence.

Sliders

Use sliders when the states represent a scale, timeline, threshold, or value range that readers should scrub.

Possible interactions

Step buttons, tabs, next/back controls, sliders, layer reveals, route highlighting, annotation cards, before/after layer changes, or synchronized text and map states.

Scroll-driven map focus

Use scrollymaps when scroll position drives the map. As the reader scrolls through text, the map changes focus, zooms to an area, reveals a feature, or highlights a geographic relationship.

A true scrollymap connects text steps to map movement. The reader scrolls through an explanation while the map pans, zooms, or changes layers to focus attention on the relevant place.

Scroll + map state

Story jobs

Best: Locate and Explain. Also useful for: Compare when scroll steps move between places, scales, or time periods.

Affordances

Spatial because the map moves through geographic space; procedural because scroll position triggers map states; motion because the transition helps connect one place or scale to the next.

Agency

Guided but reader-paced. The author controls the route through the map, while the reader controls speed and can move backward or forward by scrolling.

Text stepA paragraph, caption, or card explains what the reader should notice at this stage.
Map movementThe map pans, zooms, flies, or shifts focus to the relevant area as that step enters view.
Layer or annotation changeThe map may reveal a route, fade context, highlight a feature, or open an annotation.

Possible interactions

Scroll-triggered zoom, animated fly-to movement, route progression, layer fades, annotation reveals, marker emphasis, caption synchronization, or scroll steps that move from overview to local detail.
