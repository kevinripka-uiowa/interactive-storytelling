Tools for Building Interactive Stories

This page compares the main ways students can build and publish interactive projects: storytelling builders, general web builders, code-based hosting, embedded visualization tools, and AI-assisted coding workflows.

Core idea: the tool is not the assignment. Choose the tool that gives enough control for the story while keeping the technical responsibility manageable.

Building the project

These options determine where the story itself lives. Some tools build the whole page. Others host files you code yourself. The major trade-off is control versus responsibility.

Vibe coding

Vibe coding means using AI to help generate, revise, explain, or debug code. It can be useful for prototypes, but students still need to understand what the code is doing, test it, and take responsibility for the final result.

Classroom guidelines for vibe coding

AI can help students move faster, but it cannot replace design judgment, reporting judgment, testing, or authorship.

Use responsibly

Use AI for prototypes

Ask for a small working version first. Then revise the structure, writing, design, accessibility, and data decisions yourself.

Keep the scope visible

A good prompt should say the host, file structure, interaction, data source, mobile behavior, and accessibility requirements.

Own the final page

Students are responsible for testing, debugging, attribution, AI disclosure, and explaining how the final interactive works.
