Tilda: Blocks, Custom HTML, and Zero Block

Tilda gives you three useful levels of control: native blocks for fast production, Custom HTML for embeds and code snippets, and Zero Block for custom-designed layouts.

Core idea: start with the lowest-control option that can do the job well. Use native blocks when they fit the pattern, use Custom HTML when the interactive already exists as an embed or code snippet, and use Zero Block when the layout itself needs custom design control.

Native blocks

Native blocks are prebuilt Tilda blocks that students can configure through the regular Content and Settings panels. They are usually the easiest option when the block already matches the interactive pattern.

Custom HTML block

Use the Custom HTML block when the thing you want to add is already built elsewhere or needs a code snippet: an iframe embed, a third-party widget, custom CSS, custom JavaScript, or a small standalone interactive.

Custom HTML block

Tilda’s embed-code block is the bridge between a visual builder page and outside code. In Tilda’s help documentation, the block is listed as T123 “Embed HTML Code” in the Other category.

Embed or code snippet

What it does

Adds HTML code directly to the page body. It can hold iframe embeds, script snippets, style blocks, or code for a custom interactive.

Best for

  • Datawrapper or Flourish embeds
  • GitHub-hosted interactives in iframes
  • Small HTML/CSS/JS demos
  • Custom styles for a specific block

Watch-outs

Custom code is the student’s responsibility. Tilda’s support documentation notes that support does not advise on code added by the user.

Use this when: the interactive exists as embed code or a compact snippet, and you do not need to design the whole section visually in Zero Block.

Add the block

Open the Block Library, go to Other, and add T123: Embed HTML Code.

Paste the correct code

For Datawrapper, Flourish, YouTube, Vimeo, GitHub Pages, or another hosted page, paste the iframe/embed code. For a small custom element, paste only the needed HTML, CSS, and JavaScript.

Publish and test

Test after publishing. Some scripts, embeds, and iframes do not behave the same inside the editor as they do on the live page.

Check responsiveness

Confirm iframe height, mobile width, scrolling, and tap behavior. Custom HTML can easily create overflow or unusable mobile layouts.

Reference: Tilda Help: How to Embed HTML Code

Zero Block

Use Zero Block when the visual arrangement is the hard part: custom hero sections, designed explanatory graphics, layered layouts, or sections where the native blocks are too rigid.

Zero Block

Zero Block is Tilda’s built-in visual design editor for creating custom-designed blocks. It gives students more layout control than regular blocks, while still working inside Tilda.

Custom design control

What it does

Lets students design custom block layouts with positioned text, images, shapes, buttons, forms, animation, and responsive settings.

Best for

  • Designed intros and hero sections
  • Custom visual explainers
  • Layered image/text layouts
  • Precise responsive compositions
  • Small custom interactions inside a designed section

Watch-outs

More control also means more responsibility. Students need to check multiple screen sizes, alignment, overlap, tap targets, and readable type.

Use this when: a native block gets close but cannot produce the specific layout, layering, or visual explanation the story needs.

Good Zero Block uses

  • A custom visual header with text placed over an image.
  • A designed diagram where labels need exact placement.
  • A section that needs different arrangements on desktop and mobile.
  • A custom callout or explanatory panel that native blocks cannot match.

Poor Zero Block uses

  • Rebuilding a normal text section that a standard block already handles.
  • Using absolute positioning without checking mobile layouts.
  • Creating interactions that should really be handled by an embed or custom code.
  • Designing everything as fixed artwork instead of responsive web content.

Start from the story job

Decide whether the section needs to reveal, explain, compare, locate, participate, or create an experience.

Place the main elements

Add the text, images, shapes, buttons, or media elements that need custom positioning.

Check responsive views

Use Zero Block’s screen-size controls to adjust the composition separately for desktop, tablet, and mobile.

Add interaction only if it helps

Use links, buttons, animation, or embedded HTML only when the interaction improves the explanation or navigation.
