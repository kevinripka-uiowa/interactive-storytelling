Creating 3D Models with Mobile Scanning Apps

A mobile scanning app can turn a physical object into a digital model that viewers can rotate, zoom, and inspect.

KIRI Engine builds a model from overlapping photographs. 3D Scanner App can use the LiDAR sensor on a compatible iPhone Pro or iPad Pro to measure the surface directly.

Scanning is a capture process, not a single photograph. Move slowly around the object and collect information from every visible side. Missing angles usually become holes, stretched textures, or distorted geometry.

KIRI Engine

Uses photogrammetry, so it works by matching details across many overlapping photographs.

3D Scanner App

Uses LiDAR on compatible Apple devices and is especially useful for larger objects and spaces.

Export

Crop the model, check the texture, and export a format suited to the next tool or website.

Prepare the Object and Space

Good scanning conditions matter more than moving quickly through the app.

Choose an object that will scan well

Before scanning

Start with a matte surface

Objects with visible texture and color variation are easier to reconstruct than shiny, transparent, or uniformly colored surfaces.

Avoid movement

The object and background should remain still throughout the scan. Do not scan people, animals, plants moving in wind, or objects on an unstable surface.

Use even light

Soft, consistent light helps the app match images. Avoid hard shadows, glare, and lighting that changes while you move.

Leave room to move

You need a clear path around the object. Remove clutter that could block the camera or cause you to change distance abruptly.

Do not rotate the object during the main scan.

Move the phone around a stationary object. Changing the object's position also changes its relationship to the background, which can confuse photogrammetry.

KIRI Engine: Photo Scan

Photo Scan uses photogrammetry to identify shared visual features across overlapping photographs and reconstruct a textured mesh.

Start a Photo Scan

KIRI Engine
  1. Download and open KIRI Engine, then create or sign in to an account if prompted.
  2. Start a new project and choose Photo Scan.
  3. Choose the option to capture photographs in the app.
  4. Frame the full object with a little space around it. Keep your distance reasonably consistent.
  5. Begin with a complete circle around the object at about the height of its middle.
  6. Make another circle from a higher angle so the top and upper surfaces are visible.
  7. For a tall or complex object, add a lower-angle pass to capture areas hidden during the first two circles.
Overlap each photograph.

Move in small increments. Each new image should share much of the same visible surface as the previous image so the software can match features between them.

Review and process the scan

Cloud processing
  1. Review the image set before uploading. Remove clearly blurry or accidental photographs when the app allows it.
  2. Use automatic object masking when the object is clearly separated from a simple background.
  3. Submit the project for processing. The photographs are uploaded and the model is calculated remotely.
  4. Wait for the project to finish, then open the model and rotate it to inspect all sides.
  5. Look for holes, floating fragments, soft details, or texture streaks. A weak result usually requires a new scan with better coverage rather than repeated exporting.

Capture the bottom separately

A normal scan cannot see the surface resting on the table. For a complete object, make a second capture with the object safely repositioned, then combine or repair the geometry later in a 3D editing program.

3D Scanner App: LiDAR Scan

3D Scanner App uses the LiDAR sensor on supported iPhone Pro and iPad Pro models. It is useful for furniture, rooms, architectural details, and other subjects large enough for the sensor to measure effectively.

Choose a scan mode

3D Scanner App

Low Resolution

Use for large areas such as rooms or parts of a building. It is simpler and can be refined after capture.

High Resolution

Use for smaller subjects such as furniture or a large object when you need more surface detail.

Range

Limit the maximum depth when scanning a single object. Excluding distant surfaces can reduce clutter and improve accuracy.

Masking

Object masking can help isolate a prominent subject when it remains fully visible against a simple background.

LiDAR has a practical scale.

It is usually better for rooms, furniture, and medium-to-large objects than for very small objects with fine details.

Capture the LiDAR scan

Move slowly
  1. Open 3D Scanner App and select the scan mode appropriate for the subject.
  2. Set the range and resolution before starting. A resolution around 10–15 mm is a practical starting point for many objects.
  3. Press the red button once to begin scanning.
  4. Move slowly and smoothly around the subject. Avoid quick turns or jagged movements.
  5. Watch the live coverage display and revisit surfaces that appear incomplete.
  6. Capture the front, sides, top, and any recessed areas that the sensor can see.
  7. Press the red button again to stop the scan.
  8. Allow the app to process the mesh and apply a texture. Large scans may need manual texturing from the scan view.
Keep scans manageable.

There is no fixed capture-time limit, but extremely large scans may process poorly. Begin with a smaller area and expand only after confirming that the workflow produces a usable model.

Clean Up and Export the Model

Inspect the finished model before moving it into a web viewer, augmented-reality project, 3D editor, or interactive story.

Inspect and clean the result

Both apps
  1. Rotate the model and inspect it from every side.
  2. Crop away the floor, table, background fragments, and floating pieces that are not part of the subject.
  3. Check whether the texture aligns with the geometry. Blurred or stretched areas usually indicate weak coverage during capture.
  4. Use smoothing or mesh refinement sparingly. Heavy smoothing can remove real details along with errors.
  5. Reduce the polygon count when the model is too large for efficient web use.

Choose an export format

File formats

GLB

A strong default for the web. It can package the model and textures into one binary file and works well with web-based 3D viewers.

USDZ

Useful for Apple Quick Look and placing a model in augmented reality on iPhone, iPad, or Mac.

OBJ

A common editing format, but its texture files may be separate. Keep the OBJ, MTL, and image textures together.

STL

Common for 3D printing. It stores geometry but usually does not preserve the photographic texture.

Export from KIRI Engine

Open the finished project, choose the export or download control, select the format and quality, and save the resulting file. KIRI Engine supports common mesh formats including OBJ, FBX, STL, GLB, GLTF, USDZ, and PLY.

Export from 3D Scanner App

Open the scan detail view and choose Share. The app can share formats including USDZ, GLB, GLTF, OBJ, DAE, STL, and point-cloud data.

For a web-based interactive, begin with GLB.

It is usually the simplest format to place in a viewer such as <model-viewer> because geometry and textures can travel together in one file.
